## 2. テスト範囲

### 2.1 Webアプリケーション（OWASP Top 10）

| # | カテゴリ | テスト内容 | ツール |
|---|---|---|---|
| A01 | アクセス制御の不備 | ロール間の権限昇格、IDOR（オブジェクト直接参照） | 手動テスト |
| A02 | 暗号化の失敗 | HTTPS強制、機密データの暗号化、パスワードハッシュ | SSLScan, 手動 |
| A03 | インジェクション | SQLi, XSS, コマンドインジェクション | OWASP ZAP, sqlmap |
| A04 | 安全でない設計 | ビジネスロジックの脆弱性（入札操作、価格操作） | 手動テスト |
| A05 | セキュリティ設定ミス | デフォルト設定、不要なHTTPメソッド、エラー情報漏洩 | Nikto, 手動 |
| A06 | 脆弱なコンポーネント | 依存パッケージの既知脆弱性 | `composer audit`, `npm audit` |
| A07 | 認証の不備 | ブルートフォース、セッション固定、2FA回避 | Burp Suite |
| A08 | データ整合性の不備 | CSRFトークン検証、入力バリデーション | OWASP ZAP |
| A09 | ログ・監視の不備 | 監査ログの完全性、アラート動作確認 | 手動テスト |
| A10 | SSRF | 内部リソースへの不正アクセス | 手動テスト |

### 2.2 API セキュリティ

| テスト項目 | 内容 |
|---|---|
| 認証 | トークン偽造、期限切れトークンの再利用 |
| 認可 | 他ユーザーのデータアクセス（BOLA） |
| レート制限 | ブルートフォース耐性の確認 |
| 入力バリデーション | 不正なJSON、巨大ペイロード、特殊文字 |
| データ漏洩 | レスポンスに不要な機密情報が含まれないか |

### 2.3 インフラ

| テスト項目 | 内容 |
|---|---|
| ポートスキャン | 不要なポートが開いていないか |
| SSL/TLS | 証明書の有効性、プロトコルバージョン |
| WAF | ルールの動作確認 |
| S3 | バケットポリシーの確認 |
| IAM | 最小権限の原則 |

## 3. テスト手順

### 自動スキャン
```bash
# 依存パッケージの脆弱性チェック
composer audit
npm audit

# OWASP ZAP によるWebアプリスキャン
docker run -t owasp/zap2docker-stable zap-baseline.py \
  -t https://medaka-auction.jp -r report.html

# SSL/TLS チェック
nmap --script ssl-enum-ciphers -p 443 medaka-auction.jp
```

### 手動テスト項目

#### 認証テスト
- [ ] ログイン試行回数制限の動作確認
- [ ] パスワードリセットトークンの使い回し不可確認
- [ ] 2FA有効時のバイパス不可確認
- [ ] セッション無効化（ログアウト後のトークン使用不可確認）

#### 認可テスト
- [ ] 参加者が管理者APIにアクセス不可確認
- [ ] 他ユーザーの落札商品へのアクセス不可確認
- [ ] 出品者が他の出品者の商品を編集不可確認
- [ ] エスクロー取引の不正操作不可確認

#### 入札テスト
- [ ] 同時入札時のレースコンディション
- [ ] 負の価格での入札不可確認
- [ ] オークション終了後の入札不可確認
- [ ] 指値の不正設定不可確認

#### ファイルアップロードテスト
- [ ] 実行可能ファイルのアップロード不可確認
- [ ] ファイルサイズ制限の動作確認
- [ ] パストラバーサル攻撃の防御確認

## 4. レポート

テスト完了後に以下を含むレポートを作成:

1. **エグゼクティブサマリー**: 全体的なリスク評価
2. **発見事項一覧**: 重要度別（Critical / High / Medium / Low / Info）
3. **各脆弱性の詳細**: 再現手順、影響範囲、推奨対策
4. **修正確認**: 前回指摘事項の修正状況

---

## 5. 修正・再テスト

| 重要度 | 修正期限 | 再テスト |
|---|---|---|
| Critical | 即日対応 | 修正後即再テスト |
| High | 1週間以内 | 修正後1週間以内に再テスト |
| Medium | 1ヶ月以内 | 次回定期テストで確認 |
| Low | 次回リリースまで | 次回定期テストで確認 |
