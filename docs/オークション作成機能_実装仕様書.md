# オークション作成機能 実装仕様書

## 1. 概要

メダカライブオークションシステムのオークション作成・管理機能の実装仕様書です。
管理者がオークションイベントを作成・編集・管理する機能を提供します。

---

## 2. 機能要件

### 2.1 オークション作成機能

#### 基本情報
- **オークション名**: 必須、最大255文字
  - 例: 「2026年1月 冬の特選メダカオークション」
- **開催日**: 必須、日付選択
- **開始時刻**: 必須、デフォルト10:00
- **説明**: 任意、テキストエリア

#### オークション設定
- **レーン数**: 必須、1〜10、デフォルト6
- **デフォルト入札単位**: 必須、金額（円）、デフォルト100円
- **カウントダウン秒数**: 必須、1〜60秒、デフォルト3秒
- **保証金必須フラグ**: チェックボックス、デフォルトOFF

#### 期限設定
- **商品アップロード期限**: 任意、日時選択
  - 出品者が生体情報をアップロードできる期限
- **入金期限**: 必須、時間（h）、デフォルト24時間
  - 落札後の入金期限
- **発送期限**: 必須、時間（h）、デフォルト48時間
  - 入金確認後の発送期限

#### ステータス管理
- **preparing**: 準備中（初期状態、編集可能）
- **scheduled**: 予定（商品登録完了、編集可能）
- **live**: 開催中（編集不可）
- **finished**: 終了（編集・削除不可）
- **cancelled**: キャンセル（編集不可）

### 2.2 オークション編集機能

#### 編集可能条件
- ステータスが `preparing` または `scheduled` の場合のみ編集可能
- ステータスが `live`、`finished`、`cancelled` の場合は編集不可

#### 編集可能項目
- オークション名
- 説明
- 開催日
- 開始時刻
- レーン数（商品未登録の場合のみ）
- デフォルト入札単位
- カウントダウン秒数
- 保証金必須フラグ
- 各種期限設定

#### 編集不可項目（開催中・終了後）
- 全ての項目

### 2.3 オークション削除機能

#### 削除可能条件
- ステータスが `preparing` または `scheduled` の場合のみ削除可能
- 商品が登録されている場合は削除不可（警告表示）
- ステータスが `live`、`finished`、`cancelled` の場合は削除不可

#### 削除確認
- 削除前に確認ダイアログを表示
- 関連データ（商品、入札など）がある場合は削除不可

### 2.4 オークション一覧機能

#### 表示項目
- ID
- オークション名
- 開催日
- ステータス
- 生体数（登録済み商品数）
- レーン数
- 作成日時
- 操作ボタン

#### フィルター機能
- ステータス（全て/準備中/予定/開催中/終了/キャンセル）
- 開催日（開始日〜終了日）

#### ソート機能
- 開催日（昇順/降順）
- 作成日時（昇順/降順）

#### ページネーション
- 1ページあたり20件

#### 操作
- 詳細表示
- 編集（準備中・予定のみ）
- 削除（準備中・予定のみ、商品未登録の場合のみ）
- 生体管理へ遷移
- ライブコントロールへ遷移（開催中のみ）
- 落札者管理へ遷移（終了後）

### 2.5 オークションステータス管理

#### ステータス遷移
```
preparing (準備中)
  ↓ 商品登録完了
scheduled (予定)
  ↓ 開始時刻到達 or 手動開始
live (開催中)
  ↓ 全商品終了 or 手動終了
finished (終了)

preparing/scheduled
  ↓ キャンセル
cancelled (キャンセル)
```

#### 自動ステータス更新
- 開催日の開始時刻到達時に `scheduled` → `live` に自動更新
  - スケジューラーで1分ごとにチェック
- 全商品の入札終了時に `live` → `finished` に自動更新

#### 手動ステータス更新
- 管理者が手動で開始・終了を操作可能
- `scheduled` → `live`: 手動開始ボタン
- `live` → `finished`: 手動終了ボタン
- `preparing`/`scheduled` → `cancelled`: キャンセルボタン

## 3. データベース設計

### 3.1 テーブル: `auctions`

| カラム名 | 型 | NULL | デフォルト | 説明 |
|---------|-----|------|-----------|------|
| id | BIGINT UNSIGNED | NO | AUTO_INCREMENT | オークションID |
| title | VARCHAR(255) | NO | - | オークション名 |
| event_date | DATE | NO | - | 開催日 |
| start_time | TIME | NO | '10:00:00' | 開始時刻 |
| end_time | TIME | YES | NULL | 終了時刻（実績） |
| status | ENUM | NO | 'preparing' | ステータス |
| description | TEXT | YES | NULL | 説明 |
| lane_count | TINYINT UNSIGNED | NO | 6 | レーン数 |
| default_bid_increment | DECIMAL(10,2) | NO | 100.00 | デフォルト入札単位 |
| countdown_seconds | INT UNSIGNED | NO | 3 | カウントダウン秒数 |
| deposit_required | BOOLEAN | NO | FALSE | 保証金必須フラグ |
| upload_deadline | TIMESTAMP | YES | NULL | 商品アップロード期限 |
| payment_deadline_hours | INT UNSIGNED | NO | 24 | 入金期限（時間） |
| shipping_deadline_hours | INT UNSIGNED | NO | 48 | 発送期限（時間） |
| created_by | BIGINT UNSIGNED | NO | - | 作成者ID |
| created_at | TIMESTAMP | NO | CURRENT_TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | NO | CURRENT_TIMESTAMP | 更新日時 |

#### status ENUM値
- `preparing`: 準備中
- `scheduled`: 予定
- `live`: 開催中
- `finished`: 終了
- `cancelled`: キャンセル

#### インデックス
- PRIMARY KEY: `id`
- INDEX: `idx_event_date` (`event_date`)
- INDEX: `idx_status` (`status`)
- INDEX: `idx_event_status` (`event_date`, `status`)
- FOREIGN KEY: `created_by` → `users(id)`

#### 制約
- `lane_count`: 1〜10の範囲（CHECK制約）
- `status = 'finished'` の場合、編集・削除不可（application層で制御）

## 5. ビジネスロジック

### 5.1 ステータス自動更新ロジック

#### 自動開始
```php
// スケジューラーで1分ごとに実行
public function autoStartAuctions()
{
    $now = now();
    
    Auction::where('status', 'scheduled')
        ->whereDate('event_date', $now->toDateString())
        ->whereTime('start_time', '<=', $now->toTimeString())
        ->update([
            'status' => 'live',
            'updated_at' => $now,
        ]);
}
```

#### 自動終了
```php
// 全商品の入札終了時に呼ばれる
public function checkFinish(Auction $auction)
{
    $totalItems = $auction->items()->count();
    $finishedItems = $auction->items()
        ->where('status', 'sold')
        ->orWhere('status', 'unsold')
        ->count();
    
    if ($totalItems > 0 && $totalItems === $finishedItems) {
        $auction->update([
            'status' => 'finished',
            'end_time' => now()->toTimeString(),
        ]);
    }
}
```

### 5.2 編集可否判定ロジック

```php
public function canEdit(): bool
{
    return in_array($this->status, ['preparing', 'scheduled']);
}

public function canDelete(): bool
{
    if (!in_array($this->status, ['preparing', 'scheduled'])) {
        return false;
    }
    
    // 商品が登録されている場合は削除不可
    if ($this->items()->count() > 0) {
        return false;
    }
    
    return true;
}

public function canStart(): bool
{
    return $this->status === 'scheduled' 
        && $this->items()->count() > 0;
}

public function canCancel(): bool
{
    return in_array($this->status, ['preparing', 'scheduled']);
}
```

### 5.3 バリデーションロジック

```php
public function validateAuctionData(array $data): array
{
    // 開催日が過去でないか
    if (isset($data['event_date'])) {
        $eventDate = Carbon::parse($data['event_date']);
        if ($eventDate->lt(Carbon::today())) {
            throw new ValidationException('開催日は本日以降を指定してください。');
        }
    }
    
    // アップロード期限が開催日より前か
    if (isset($data['upload_deadline']) && isset($data['event_date'])) {
        $uploadDeadline = Carbon::parse($data['upload_deadline']);
        $eventDate = Carbon::parse($data['event_date']);
        if ($uploadDeadline->gte($eventDate)) {
            throw new ValidationException('アップロード期限は開催日より前に設定してください。');
        }
    }
    
    return $data;
}
```

## 14. 注意事項

### 開催済みオークションの扱い
- **編集不可**: 開催中・終了後のオークションは編集できません
- **削除不可**: 開催中・終了後のオークションは削除できません
- **データ保持**: 監査目的で全てのデータを保持します

### レーン数の変更
- 商品が登録されている場合、レーン数は変更できません
- レーン割り当てとの整合性を保つため

### 日時の扱い
- タイムゾーン: Asia/Tokyo
- 開催日は当日以降のみ指定可能
- 自動開始は開始時刻の1分以内に実行
