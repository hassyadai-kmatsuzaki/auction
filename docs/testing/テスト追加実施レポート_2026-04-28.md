### Cypress E2E の skip 理由

| Webhook 受信 | 外部からの POST が必要 |
| AI (OpenAI 連携) | 外部 API 必須 |
| 性能・セキュリティ | staging 環境必須 |

### 推奨カスタムコマンド拡張

skip を解除するには `cypress/support/commands.ts` に以下を追加:

| コマンド | 用途 |
|---|---|
| `cy.apiLoginAs(role)` | API トークン経由の高速ログイン |
| `cy.seedWonItem(params)` | 指定状態の WonItem を生成 |
| `cy.runSchedule(taskName)` | staging で `php artisan schedule:run` を発火 |
| `cy.mailbox(email)` | MailHog 検索 API ラッパ |
| `cy.lineSent(userId?)` | LINE テスト Bot の送信履歴取得 |
| `cy.downloadPdf(url)` | PDF バイナリ取得 → `pdf-parse` でテキスト化 |

加えて `cypress.config.ts` に `task` ハンドラ (`pdfParse(buffer)`, `sshExec(cmd)`) を追加。
