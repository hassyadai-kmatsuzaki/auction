## リスクと対策

| リスク | 影響 | 対策 |
|-------|------|------|
| PDF 生成に時間がかかる（大量落札時） | オークション終了処理が遅延 | Queue（非同期ジョブ）で PDF 生成・メール送信を実行 |
| 銀行 CSV フォーマットが銀行ごとに異なる | 自動消し込みの精度低下 | まず主要銀行1行のフォーマットに対応 → 順次追加 |
| LINE Messaging API のレート制限 | 大量通知時にエラー | 送信をキューに入れてリトライ制御 |
| スナップショットのデータ量が増大 | DB 容量 | JSON カラムは圧縮効率が高いため当面問題なし。年単位でアーカイブ検討 |
| インボイス制度の法改正 | PDF フォーマット変更が必要 | PDF テンプレートを Blade で管理し、変更を容易に |
