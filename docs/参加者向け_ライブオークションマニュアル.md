## 1. はじめに

メダカオークションは、メダカの生体をリアルタイムで競り落とすライブオークションシステムです。スマートフォンやPCのブラウザからどなたでも参加できます。

### 参加に必要なもの

- アカウント登録（メールアドレス）
- インターネット接続（Wi-Fi推奨）
- 対応ブラウザ（Chrome最新版推奨）

### メニュー一覧

| メニュー | 内容 |
|---------|------|
| ホーム | 開催中・開催予定のオークション確認 |
| オークション | オークション一覧・出品一覧 |
| お気に入り | お気に入り登録した商品の管理 |
| 落札管理 | 落札商品の支払い・配送状況確認 |
| 設定 | プロフィール・通知設定・LINE連携 |

## 2. オークションの流れ

```
開催予定 → 入場開始 → 待機室 → 開始カウントダウン → ライブ競り → 終了
```

### 全体の流れ

| ステップ | 内容 | あなたの操作 |
|---------|------|-------------|
| 1. 開催予定 | オークションが告知されます | 出品一覧を確認、指値を事前設定 |
| 2. 入場開始 | 開始30分前から入場可能 | 「待機室へ入室」ボタンを押す |
| 3. 待機室 | 開始を待ちます | そのまま待機（自動で切り替わります） |
| 4. 開始カウントダウン | 10秒のカウントダウン | 画面を確認 |
| 5. ライブ競り | 商品ごとに入札 | 入札ボタンで参加・離脱 |
| 6. 終了 | 全商品の競りが終了 | 落札結果を確認、支払い手続き |

## 3. 入場から開始まで

### 入場のタイミング

- オークション開始の **30分前** から入場できます（運営により変更される場合があります）
- 入場前にアクセスすると「入室可能まで ○時間○分○秒」と表示されます
- 入場可能になると「待機室へ入室」ボタンが表示されます

### 待機室

- 入場後は待機室で開始を待ちます
- **開始されると自動的にライブ画面に切り替わります**（手動操作は不要）

### 開始カウントダウン

- オークション開始時に **10秒のカウントダウン** が表示されます
- カウントダウン終了後、各レーンの最初の商品が表示されます

### 同意画面（表示される場合）

- 一部のオークションでは、開始前に確認画面が表示されます
- 内容：「画像は同じ品種のイメージ画像です。実際の映像は詳細ボタンよりご確認ください。」
- 「同意してオークションに参加する」を押すとライブ画面に進みます

|----|------|

| 黄色 | 残り3秒以下（まもなく終了） |

| 表示 | 意味 |
|------|------|
| リアルタイム接続中 | WebSocketで正常接続 |

## 5. 入札の方法

### 入札ON（参加する）

1. 入札したい商品のレーンカードで **「入札する」** ボタンを押します
2. ボタンが **「入札中」（緑色）** に変わります
3. カードの枠が **緑色に光ります**（落札権利の表示）

### 入札OFF（離脱する）

1. 入札中のレーンカードで **「入札中」** ボタンを押します
2. ボタンが **「入札する」** に戻ります

### 入札できないタイミング

| タイミング | 表示 | 理由 |
|-----------|------|------|
| 入札開始待機中 | 「入札準備中...」（グレー） | 商品切り替え直後の待機時間 |
| ブロック中 | 「ブロック中 N秒」（グレー） | 誤タップ防止のための一時停止 |

### 注意事項

- **入札ボタンの二重押し** は自動で防止されます
- 通信エラーが発生した場合、入札状態は自動で元に戻ります
- 複数のレーンに同時に入札できます

## 6. カウントダウンの仕組み

### 3つのフェーズ

オークションの各商品は、以下の3つのフェーズを繰り返します。

#### フェーズ1：入札開始待機（pre_bid）

- 商品が切り替わった直後の **約5秒間**
- 画面に「入札開始まで N秒」と表示されます
- **この間は入札できません**
- 商品情報を確認する時間です

#### フェーズ2：入札カウントダウン（bidding）

- **約5秒間**（金額帯により変動）
- 入札ボタンが有効になります
- カウントダウンが0になると結果が確定します

#### フェーズ3：ブロック（freeze / 誤タップ防止）

- 価格が上昇した直後の **約1秒間**
- 画面に「ブロック中 N秒」と表示されます
- **この間は入札できません**
- 誤って入札ボタンを押してしまうことを防ぎます

### フェーズの流れ

```
商品表示 → [入札開始待機 5秒] → [入札カウントダウン 5秒]
                                         │
                              ┌──────────┴──────────┐
                              │                      │
                        入札者2名以上            入札者0〜1名
                              │                      │
                        価格上昇                  結果確定
                              │                 （落札 or 流札）
                    [ブロック 1秒]                    │
                              │                 次の商品へ
                    [入札カウントダウン 5秒]
                              │
                           （繰り返し）
```

### 金額帯によるカウントダウン秒数の変動

カウントダウンの秒数は、現在の価格帯によって変わる場合があります。高額商品ほど長い時間が設定されることがあります。

## 7. 価格上昇のルール

### 価格が上がるタイミング

価格は以下の2つのタイミングで上昇します。

#### 1. 即時上昇（2人目が入札した瞬間）

- 1人が入札中に、2人目が入札ボタンを押した瞬間
- **即座に** 価格が1段階上昇します

#### 2. カウントダウン終了時（2名以上入札中）

- 入札カウントダウンが0になった時点で2名以上が入札中の場合
- 価格が1段階上昇します

### 上昇幅テーブル（デフォルト）

| 現在価格 | 上昇幅 | 例 |
|---------|--------|-----|
| ¥0 〜 ¥999 | +¥50 | ¥500 → ¥550 |
| ¥1,000 〜 ¥4,999 | +¥100 | ¥3,000 → ¥3,100 |
| ¥5,000 〜 ¥9,999 | +¥500 | ¥7,000 → ¥7,500 |
| ¥10,000 〜 ¥49,999 | +¥1,000 | ¥25,000 → ¥26,000 |
| ¥50,000 以上 | +¥5,000 | ¥60,000 → ¥65,000 |

※ オークションごとにカスタム設定される場合があります。

## 8. 落札権利と自動離脱のルール

### 落札権利とは

- 入札中のユーザーが **1名のみ** の状態でカウントダウンが0になると、その方が **落札** となります
- つまり「入札中」の状態 ＝ 落札権利を持っている状態です

### 自動離脱のルール（重要）

**価格が上昇した際、落札権利者以外は自動的に入札OFFになります。**

これはオークションの公平性を保つための仕組みです。

#### 誰が残るのか？

| 条件 | 結果 |
|------|------|
| **最後に入札した人**（価格を上げた人） | 1回分だけ残る |
| **有効な指値を持っている人**（指値 > 新価格） | 残る（自動で入札継続） |
| **上記以外の全員** | 自動離脱（入札OFF） |

#### 自動離脱された場合

1. 画面に **「金額が上昇しました。再度入札してください。」** と通知が表示されます
2. 入札ボタンが **「入札する」** に戻ります
3. 再度入札したい場合は、もう一度 **「入札する」** ボタンを押してください

#### 落札権利者の注意点

- 最後に入札した人は **1回分のみ** 落札権利が保持されます
- 次の価格上昇時には、再度入札しないと自動離脱されます
- **指値を設定している場合は、指値の範囲内で自動的に入札が継続されます**

### 具体例

```
現在価格: ¥3,000
入札者: Aさん（入札中）、Bさん（入札中）、Cさん（入札中）

→ カウントダウン終了、価格が ¥3,100 に上昇

結果:
  Cさん（最後の入札者）→ 入札継続（落札権利者）
  Aさん → 自動離脱（再入札が必要）
  Bさん → 自動離脱（再入札が必要）

→ ブロック 1秒 → 入札カウントダウン 5秒

  Aさんが再入札 → 価格が ¥3,200 に上昇
  Aさん（最後の入札者）→ 入札継続
  Cさん → 自動離脱（再入札が必要）
```

## 9. 指値（上限価格）機能

### 指値とは

**指値（さしね）** とは、「この価格までなら自動で入札を続ける」という上限価格を事前に設定する機能です。

### 指値のメリット

- 画面を見続けなくても、設定した価格まで自動で入札が継続されます
- 価格上昇時の自動離脱から保護されます（指値の範囲内であれば）
- 予算オーバーを防げます

### 指値の設定方法

1. レーンカードまたは出品一覧の **「上限設定」** バッジを押します
2. 指値設定ダイアログが開きます
3. 金額を入力します

#### クイック入力

現在価格（または開始価格）を基準に、簡単に指値を設定できます。

| ボタン | 計算 | 例（基準 ¥1,000） |
|--------|------|-------------------|
| ×1.5 | 基準 × 1.5 | ¥1,500 |
| ×2 | 基準 × 2 | ¥2,000 |
| ×2.5 | 基準 × 2.5 | ¥2,500 |
| ×3 | 基準 × 3 | ¥3,000 |

#### カスタム入力

任意の金額を直接入力できます。

### 指値の動作

#### オークション開始前に設定した場合

- 商品がライブになった時点で **自動的に入札ON** になります
- 指値の範囲内であれば、価格上昇時も入札が継続されます

#### ライブ中に設定した場合

- 現在価格 < 指値の場合：**即座に入札ON** になります
- 現在価格 ≥ 指値の場合：入札されません（設定のみ保存）

### 指値が発動するとき

現在価格が指値に達すると、以下が起こります。

1. **自動的に入札OFF** になります
2. 画面に **「上限価格に達したため自動的に入札オフになりました」** と通知が表示されます
3. 指値バッジがグレー（取り消し線付き）に変わります
4. LINE通知を設定している場合は通知が届きます

### 指値と自動離脱の関係

| 状態 | 価格上昇時の動作 |
|------|----------------|
| 指値あり・指値 > 新価格 | **入札継続**（自動離脱されない） |
| 指値あり・指値 ≤ 新価格 | **自動離脱**（指値発動） |
| 指値なし | **自動離脱**（再入札が必要） |

### 指値が2名以上ある場合の開始価格

オークション開始時に指値が複数設定されている場合、価格が自動調整されます。

#### 例1：Aさん 40,000円、Bさん 50,000円

1. 開始価格から、Aさんの指値（40,000円）を超える次の上昇金額まで価格が上昇
2. 例：41,000円からスタート
3. Aさんは指値発動で自動離脱
4. Bさんが41,000円で落札権利を持ってカウントダウン開始

#### 例2：Aさん 30,000円、Bさん 50,000円、Cさん 80,000円

1. 価格が31,000円に調整
2. Aさんは指値発動で自動離脱
3. Bさん・Cさんが入札継続

### 指値の変更・解除

- **変更**: 指値ダイアログで新しい金額を入力して「設定する」
- **解除**: 指値ダイアログで「設定を解除」を押す
  - 解除すると入札からも離脱します

### 注意事項

- 指値は **1円以上** で設定してください
- 現在価格以下の指値を設定すると、即座に発動します（入札しません）
- 指値発動後に再度入札する場合は、指値を更新するか手動で入札してください

## 10. 落札と支払い

### 落札の確定

- カウントダウンが0になった時点で **入札者が1名のみ** の場合、その方が落札者です
- 落札時には画面に **お祝いオーバーレイ**（紙吹雪 + 「落札おめでとうございます！」）が約4秒間表示されます

### 流札（不成立）

- カウントダウンが0になった時点で **入札者が0名** の場合、その商品は流札（不成立）となります
- 流札後は自動的に次の商品に移ります

### 落札結果の確認

#### ライブ画面内

- 画面下部の **「あなたの落札一覧」** パネルに、落札した商品と合計金額が表示されます

#### オークション終了後

- 終了画面に落札結果の一覧が表示されます
- 「落札管理へ」ボタンから詳細を確認できます

### 落札管理画面

| 項目 | 内容 |
|------|------|
| 落札単価 | 1匹あたりの落札価格 |
| 数量 | 匹数 |
| 手数料 | 購入者手数料 |
| 合計金額（税込） | 落札単価 × 数量 + 手数料 |
| 支払い期限 | 支払い期限日時 |
| 支払い状況 | 支払い待ち → 入金確認済み |
| 配送状況 | 発送待ち → 配送中 → 配達完了 |

### 支払いの流れ

1. **支払い待ち**: 「請求書を確認・支払い」ボタンから支払い手続き
2. **入金確認済み**: 運営が入金を確認
3. **発送準備中**: 出品者が発送準備
4. **配送中**: 発送完了（伝票番号が表示されます）
5. **配達完了**: お届け完了

### 配送先の変更

- **入金確認前** であれば、配送先住所を変更できます
- 入金確認後は変更できません

## 11. お気に入り機能

### お気に入りの登録

- 出品一覧やライブ画面で、商品のハートアイコンを押すとお気に入りに登録できます
- 指値を設定すると自動的にお気に入りに追加されます

### お気に入り画面

- 登録した商品の一覧を確認できます
- 各商品の現在のステータス（出品中・入札中・落札済み等）が表示されます
- 指値の設定状況も確認できます
- ライブ画面や出品一覧への直接リンクがあります

## 12. 通知設定

### 通知の種類

| 通知 | 内容 | タイミング |
|------|------|-----------|
| 新規オークション | 新しいオークションが公開された | オークション公開時 |
| オークション開始 | オークションが開始された | 開始時 |
| 落札通知 | 商品を落札した | 落札確定時 |
| 入金確認 | 入金が確認された | 入金確認時 |
| 発送通知 | 商品が発送された | 発送時 |
| 指値発動 | 上限価格に達した | 指値発動時 |

### 通知方法

- **メール通知**: 設定画面でON/OFF切り替え
- **LINE通知**: LINE連携後に利用可能

### LINE連携

1. 設定画面の「通知設定」タブを開く
2. 「LINE連携」セクションから連携手続き
3. 連携後、各通知のLINE通知をON/OFFできます

## 13. よくある質問（FAQ）

### Q1. 入札ボタンが押せません

**A.** 以下のタイミングでは入札ボタンが無効になります。
- **入札開始待機中**（商品切り替え直後の約5秒間）
- **ブロック中**（価格上昇直後の約1秒間）

少し待ってから再度お試しください。

### Q2. 入札していたのに勝手に入札OFFになりました

**A.** 価格が上昇した際、落札権利者以外は自動的に入札OFFになります。これは正常な動作です。再度入札したい場合は「入札する」ボタンを押してください。指値を設定しておくと、指値の範囲内で自動的に入札が継続されます。

### Q3. 指値を設定しているのに離脱しました

**A.** 現在価格が指値に達した（または超えた）ため、指値が発動して自動離脱しました。より高い金額で入札を続けたい場合は、指値を更新するか、手動で入札してください。

### Q4. 画面が更新されません

**A.** 接続状態を確認してください。「ポーリング中」と表示されている場合、一時的に接続が不安定です。通常は自動で復旧しますが、改善しない場合はページを更新してください。

### Q5. 複数のレーンに同時に入札できますか？

**A.** はい、複数のレーンに同時に入札できます。ただし、各レーンの状況を把握しながら入札してください。

### Q6. 落札後のキャンセルはできますか？

**A.** 落札確定後のキャンセルはできません。入札は慎重に行ってください。予算を超えないよう、指値機能のご利用をおすすめします。

### Q7. 配送先を間違えました

**A.** 入金確認前であれば、落札管理画面から配送先を変更できます。入金確認後は変更できませんのでご注意ください。

### Q8. 「ブロック中」とは何ですか？

**A.** 価格が上昇した直後に表示される短い待機時間（約1秒）です。価格変動直後に誤ってボタンを押してしまうことを防ぐための仕組みです。ブロックが終わると自動的に入札可能になります。

### Q9. 指値はいつ設定するのがよいですか？

**A.** オークション開始前に設定しておくことをおすすめします。開始前に設定しておくと、商品がライブになった時点で自動的に入札ONになります。ライブ中でも設定・変更は可能です。

### Q10. 同じ価格で2人が入札したらどうなりますか？

**A.** 2人以上が同じ価格で入札中の場合、カウントダウン終了時に価格が1段階上昇します。最後に入札した人が落札権利者となり、それ以外の人は自動離脱されます。

6. カウントダウンが0になり、他に入札者がいなかったため **落札成功！**
7. 画面に紙吹雪が表示され「落札おめでとうございます！」
8. 落札管理画面から支払い手続きを行う

**ポイント**: 初めての方は1つのレーンに集中するのがおすすめです。

### ユースケース2：指値を使った自動入札

> **状況**: 佐藤さんは仕事中にオークションがあるため、指値を活用します。

1. オークション開始前に出品一覧を確認
2. 欲しい品種に **指値 ¥5,000** を設定（クイック入力 ×2 を使用）
3. オークション開始 → 自動的に入札ON
4. 他の参加者と競り合い、価格が上昇
5. ¥4,500 まで上昇 → 指値の範囲内なので **自動で入札継続**
6. ¥5,000 に到達 → 指値発動、**自動で入札OFF**
7. LINE通知で「上限価格に達しました」と通知が届く

**ポイント**: 予算を決めている場合は指値を設定しておくと安心です。

### ユースケース3：複数レーンでの同時入札

> **状況**: 鈴木さんは3つのレーンで同時に入札を試みます。

3. レーン2：2人入札中 → 価格上昇 → 自動離脱 → 再入札を判断
4. レーン3：カウントダウン中に離脱を決意 → 「入札中」ボタンで離脱

**ポイント**: 複数レーンを同時に見る場合は、各レーンのカウントダウンに注意しましょう。

### ユースケース4：価格上昇後の再入札

> **状況**: 山田さんは競り合いの中で再入札を繰り返します。

1. ¥3,000 で入札ON
2. 高橋さんも入札 → 即座に ¥3,100 に上昇
3. 山田さんは自動離脱、**「金額が上昇しました。再度入札してください。」** と通知
4. ブロック（1秒）が終了
5. 山田さんが再度「入札する」→ 即座に ¥3,200 に上昇（山田さんが落札権利者）
6. カウントダウン5秒 → 高橋さんが再入札 → ¥3,300 に上昇
7. 山田さんが自動離脱 → 予算オーバーのため入札しない
8. カウントダウン終了 → 高橋さんが ¥3,300 で **落札**

**ポイント**: 予算を事前に決めておき、無理な追いかけは避けましょう。

### ユースケース5：指値ユーザー vs 手動入札ユーザー

> **状況**: Aさん（指値 ¥50,000）と Bさん（手動入札）が競り合います。

1. 現在価格 ¥42,000、Aさんは指値で自動入札中
2. Bさんが入札 → ¥43,000 に上昇
3. Bさんが落札権利者、Aさんは **指値で保護されて入札継続**
4. カウントダウン終了 → 2人入札中 → ¥44,000 に上昇
5. Bさんは自動離脱（再入札が必要）、Aさんは指値で継続
6. Bさんが再入札 → ¥45,000 に上昇
7. ...繰り返し...
8. ¥50,000 に到達 → Aさんの指値発動、自動離脱
9. Bさんが ¥50,000 で **落札**

**ポイント**: 指値を設定していると、手動で再入札する手間が省けます。

### ユースケース6：開始時に指値が複数設定されている場合

> **状況**: 開始前にAさん（¥40,000）とBさん（¥50,000）が指値を設定。

1. オークション開始、開始価格 ¥30,000
2. システムが自動で価格を調整 → ¥41,000（Aさんの指値を超える次の上昇金額）
3. Aさんの指値発動 → 自動離脱
4. Bさんが ¥41,000 で落札権利を持ってカウントダウン開始
5. 誰も入札しなければ → Bさんが ¥41,000 で **落札**
6. Aさんが追いかけて手動入札した場合 → ¥42,000 に上昇、競り合い続行

**ポイント**: 指値が高いほど有利ですが、最終的な落札価格は競合状況で決まります。

### ユースケース7：ネットワーク切断からの復帰

4. ネットワーク復旧 → 自動的にWebSocket再接続
5. 接続状態が「リアルタイム接続中」に戻る
6. 最新の入札状態が自動的に同期される

**ポイント**: 一時的な切断でも入札状態はサーバーに保持されています。ただし、切断中に価格が上昇して自動離脱されている可能性があります。

### ユースケース8：流札後の次の商品

## 付録：用語集

| 用語 | 説明 |
|------|------|
| レーン | 同時に進行する競りの列。複数レーンで同時に異なる商品が競られます |
| カウントダウン | 入札の残り時間。0になると結果が確定します |
| ブロック（フリーズ） | 価格上昇直後の短い待機時間。誤タップ防止のためです |
| 入札開始待機（pre_bid） | 商品切り替え直後の待機時間。商品情報を確認する時間です |
| 指値（さしね） | 上限価格。この価格まで自動で入札が継続されます |
| 落札権利 | 入札中の状態。カウントダウン終了時に1名のみなら落札確定 |
| 自動離脱 | 価格上昇時に、落札権利者以外が自動的に入札OFFになること |
| 流札（りゅうさつ） | 入札者がいない状態でカウントダウンが終了し、不成立になること |
| プレミアム | 特に注目度の高い商品に付けられるラベル |
| 上昇幅 | 価格が上がる際の1回あたりの金額。価格帯により異なります |
