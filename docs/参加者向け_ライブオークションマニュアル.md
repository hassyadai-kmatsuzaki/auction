## 1. はじめに

メダカオークションは、メダカの生体をリアルタイムで競り落とすライブオークションシステムです。スマートフォンやPCのブラウザからどなたでも参加できます。

### 参加に必要なもの

- アカウント登録（メールアドレス）
- インターネット接続（Wi-Fi推奨）
- 対応ブラウザ（Chrome最新版推奨）

### メニュー一覧

| メニュー | 内容 |
|---------|------|
| ホーム | 開催中・開催予定のオークション確認 |
| オークション | オークション一覧・出品一覧 |
| お気に入り | お気に入り登録した商品の管理 |
| 落札管理 | 落札商品の支払い・配送状況確認 |
| 設定 | プロフィール・通知設定・LINE連携 |

## 2. オークションの流れ

```
開催予定 → 入場開始 → 待機室 → 開始カウントダウン → ライブ競り → 終了
```

### 全体の流れ

| ステップ | 内容 | あなたの操作 |
|---------|------|-------------|
| 1. 開催予定 | オークションが告知されます | 出品一覧を確認、指値を事前設定 |
| 2. 入場開始 | 開始30分前から入場可能 | 「待機室へ入室」ボタンを押す |
| 3. 待機室 | 開始を待ちます | そのまま待機（自動で切り替わります） |
| 4. 開始カウントダウン | 10秒のカウントダウン | 画面を確認 |
| 5. ライブ競り | 商品ごとに入札 | 入札ボタンで参加・離脱 |
| 6. 終了 | 全商品の競りが終了 | 落札結果を確認、支払い手続き |

## 3. 入場から開始まで

### 入場のタイミング

- オークション開始の **30分前** から入場できます（運営により変更される場合があります）
- 入場前にアクセスすると「入室可能まで ○時間○分○秒」と表示されます
- 入場可能になると「待機室へ入室」ボタンが表示されます

### 待機室

- 入場後は待機室で開始を待ちます
- **開始されると自動的にライブ画面に切り替わります**（手動操作は不要）

### 開始カウントダウン

- オークション開始時に **10秒のカウントダウン** が表示されます
- カウントダウン終了後、各レーンの最初の商品が表示されます

### 同意画面（表示される場合）

- 一部のオークションでは、開始前に確認画面が表示されます
- 内容：「画像は同じ品種のイメージ画像です。実際の映像は詳細ボタンよりご確認ください。」
- 「同意してオークションに参加する」を押すとライブ画面に進みます

## 4. ライブ画面の見方

### 画面構成

```
┌─────────────────────────────────────┐
│ オークションタイトル                    │
│ 2/3レーン進行中  [出品一覧] [更新]     │
│ リアルタイム接続中                      │
├─────────────────────────────────────┤
│ ┌───────────┐  ┌───────────┐        │
│ │ レーン1    │  │ レーン2    │        │
│ │ [サムネイル]│  │ [サムネイル]│        │
│ │ No.1       │  │ No.5       │        │
│ │ 品種名     │  │ 品種名     │        │
│ │ 出品者/数量│  │ 出品者/数量│        │
│ │ 残り 5秒   │  │ 残り 3秒   │        │
│ │ ¥3,000/1匹│  │ ¥5,500/1匹│        │
│ │ [入札する] │  │ [入札中]   │        │
│ └───────────┘  └───────────┘        │
├─────────────────────────────────────┤
│ あなたの入札状況                       │
│ レーン2: ○○メダカ                     │
├─────────────────────────────────────┤
│ 次の商品                              │
│ [次の商品カード] [次の商品カード]       │
├─────────────────────────────────────┤
│ あなたの落札一覧（2件）                │
│ 合計金額: ¥12,000                     │
└─────────────────────────────────────┘
```

### レーンカードの情報

| 表示項目 | 説明 |
|---------|------|
| レーン名 | レーン番号またはカスタム名 |
| No.○ | 出品番号 |
| 品種名 | メダカの品種 |
| 出品者 / 数量 | 出品者名と匹数（例：出品者：サバンナ / 数量：100匹） |
| プレミアム | プレミアム商品の場合にバッジ表示 |
| サムネイル | 商品画像（ない場合は「NO IMAGE」） |
| カウントダウン | 残り秒数（色で状態が変わります） |
| 現在単価 | 現在の1匹あたりの価格 |
| 入札ボタン | 入札する / 入札中 |
| 指値バッジ | 上限価格の設定状況 |
| 詳細アイコン | 商品の詳細情報を表示 |

### カウントダウンの色

| 色 | 状態 |
|----|------|
| 青 | 通常のカウントダウン |
| 黄色 | 残り3秒以下（まもなく終了） |
| 赤 | 競合中（2名以上が入札中） |
| グレー | ブロック中（誤タップ防止） |

### 接続状態

| 表示 | 意味 |
|------|------|
| リアルタイム接続中 | WebSocketで正常接続 |
| ポーリング中 | 一時的に接続が不安定（3秒ごとに更新） |

## 5. 入札の方法

### 入札ON（参加する）

1. 入札したい商品のレーンカードで **「入札する」** ボタンを押します
2. ボタンが **「入札中」（緑色）** に変わります
3. カードの枠が **緑色に光ります**（落札権利の表示）

### 入札OFF（離脱する）

1. 入札中のレーンカードで **「入札中」** ボタンを押します
2. ボタンが **「入札する」** に戻ります

### 入札できないタイミング

| タイミング | 表示 | 理由 |
|-----------|------|------|
| 入札開始待機中 | 「入札準備中...」（グレー） | 商品切り替え直後の待機時間 |
| ブロック中 | 「ブロック中 N秒」（グレー） | 誤タップ防止のための一時停止 |

### 注意事項

- **入札ボタンの二重押し** は自動で防止されます
- 通信エラーが発生した場合、入札状態は自動で元に戻ります
- 複数のレーンに同時に入札できます

## 6. カウントダウンの仕組み

### 3つのフェーズ

オークションの各商品は、以下の3つのフェーズを繰り返します。

#### フェーズ1：入札開始待機（pre_bid）

- 商品が切り替わった直後の **約5秒間**
- 画面に「入札開始まで N秒」と表示されます
- **この間は入札できません**
- 商品情報を確認する時間です
- 事前に指値が設定されている場合、この待機中に自動入札と価格調整が行われます

#### フェーズ2：入札カウントダウン（bidding）

- **約5秒間**（金額帯により変動）
- 入札ボタンが有効になります
- カウントダウンが0になると結果が確定します

#### フェーズ3：ブロック（freeze / 誤タップ防止）

- 価格が上昇した直後の **約1秒間**
- 画面に「ブロック中 N秒」と表示されます
- **この間は入札できません**
- 誤って入札ボタンを押してしまうことを防ぎます

### フェーズの流れ

```
商品表示 → [入札開始待機 5秒] → [入札カウントダウン 5秒]
                                         │
                              ┌──────────┴──────────┐
                              │                      │
                        入札者2名以上            入札者0〜1名
                              │                      │
                        価格上昇                  結果確定
                              │                 （落札 or 流札）
                    [ブロック 1秒]                    │
                              │                 次の商品へ
                    [入札カウントダウン 5秒]
                              │
                           （繰り返し）
```

### 金額帯によるカウントダウン秒数の変動

カウントダウンの秒数は、現在の価格帯によって変わる場合があります。高額商品ほど長い時間が設定されることがあります。

## 7. 価格上昇のルール

### 価格が上がるタイミング

価格は以下の3つのタイミングで上昇します。

#### 1. 即時上昇（2人目が入札した瞬間）

- 1人が入札中に、2人目が入札ボタンを押した瞬間
- **即座に** 価格が1段階上昇します

#### 2. カウントダウン終了時（2名以上入札中）

- 入札カウントダウンが0になった時点で2名以上が入札中の場合
- 価格が1段階上昇します

#### 3. 指値による自動調整

- 指値が2名以上設定されている場合、最低指値を超える次の上昇金額まで一気に価格が上昇します
- 商品切替時（開始時含む）およびライブ中に指値が追加された時に発生します

### 上昇幅テーブル（デフォルト）

| 現在価格 | 上昇幅 | 例 |
|---------|--------|-----|
| ¥0 〜 ¥999 | +¥50 | ¥500 → ¥550 |
| ¥1,000 〜 ¥4,999 | +¥100 | ¥3,000 → ¥3,100 |
| ¥5,000 〜 ¥9,999 | +¥500 | ¥7,000 → ¥7,500 |
| ¥10,000 〜 ¥49,999 | +¥1,000 | ¥25,000 → ¥26,000 |
| ¥50,000 以上 | +¥5,000 | ¥60,000 → ¥65,000 |

※ オークションごとにカスタム設定される場合があります。

## 8. 落札権利と自動離脱のルール

### 落札権利とは

- 入札中のユーザーが **1名のみ** の状態でカウントダウンが0になると、その方が **落札** となります
- つまり「入札中」の状態 ＝ 落札権利を持っている状態です

### 自動離脱のルール（重要）

**価格が上昇した際、以下のルールに基づいて入札者が整理されます。**

これはオークションの公平性を保つための仕組みです。

#### 誰が残るのか？（指値ユーザーがいる場合）

| 条件 | 結果 |
|------|------|
| **有効な指値を持っている人**（指値 > 新価格） | 残る（自動で入札継続） |
| **指値が最も高い人** | **落札権利者**（次の価格上昇でも権利を保持し続ける） |
| **指値なし・指値発動済みの全員**（手動入札者含む） | **自動離脱**（再入札が必要） |

**指値ユーザーがいる場合、手動入札者は最後に入札した人であっても自動離脱されます。**

#### 誰が残るのか？（指値ユーザーがいない場合）

| 条件 | 結果 |
|------|------|
| **最後に入札した人**（価格を上げた人） | 1回分だけ残る |
| **上記以外の全員** | 自動離脱（入札OFF） |

#### 自動離脱された場合

1. 画面に **「金額が上昇しました。再度入札してください。」** と通知が表示されます
2. 入札ボタンが **「入札する」** に戻ります
3. 再度入札したい場合は、もう一度 **「入札する」** ボタンを押してください

#### 落札権利者の注意点

- **指値最高者がいる場合**: 指値が最も高いユーザーが落札権利者として維持されます。手動入札者が入札しても、価格上昇時に指値最高者が落札権利者に戻ります
- **指値ユーザーがいない場合**: 最後に入札した人が1回分のみ落札権利を保持します。次の価格上昇時には再度入札が必要です
- **指値を設定している場合は、指値の範囲内で自動的に入札が継続されます**

### 具体例1：指値ユーザーがいない場合

```
現在価格: ¥3,000
入札者: Aさん（手動）、Bさん（手動）、Cさん（手動）

→ カウントダウン終了、価格が ¥3,100 に上昇

結果:
  Cさん（最後の入札者）→ 入札継続（落札権利者）
  Aさん → 自動離脱（再入札が必要）
  Bさん → 自動離脱（再入札が必要）

→ ブロック 1秒 → 入札カウントダウン 5秒

  Aさんが再入札 → 価格が ¥3,200 に上昇
  Aさん（最後の入札者）→ 入札継続
  Cさん → 自動離脱（再入札が必要）
```

### 具体例2：指値ユーザーがいる場合

```
現在価格: ¥10,000
入札者: Aさん（指値 ¥20,000）、Bさん（手動）

→ Bさんが入札、即座に ¥11,000 に上昇

結果:
  Aさん（指値最高者）→ 入札継続（落札権利者）
  Bさん → 自動離脱（指値ユーザーがいるため、手動入札者は離脱）

→ ブロック 1秒 → 入札カウントダウン 5秒

  Bさんが再入札 → ¥12,000 に上昇
  Aさん（指値最高者）→ 入札継続（落札権利者を維持）
  Bさん → 再び自動離脱

  ...Aさんの指値 ¥20,000 に到達するまで繰り返し...

  ¥20,000 到達 → Aさんの指値発動、自動離脱
  Bさんが入札中なら → Bさんが ¥20,000 で落札
```

## 9. 指値（上限価格）機能

### 指値とは

**指値（さしね）** とは、「この価格までなら自動で入札を続ける」という上限価格を事前に設定する機能です。

### 指値のメリット

- 画面を見続けなくても、設定した価格まで自動で入札が継続されます
- 価格上昇時の自動離脱から保護されます（指値の範囲内であれば）
- 予算オーバーを防げます

### 指値の設定方法

1. レーンカードまたは出品一覧の **「上限設定」** バッジを押します
2. 指値設定ダイアログが開きます
3. 金額を入力します

#### クイック入力

現在価格（または開始価格）を基準に、簡単に指値を設定できます。

| ボタン | 計算 | 例（基準 ¥1,000） |
|--------|------|-------------------|
| ×1.5 | 基準 × 1.5 | ¥1,500 |
| ×2 | 基準 × 2 | ¥2,000 |
| ×2.5 | 基準 × 2.5 | ¥2,500 |
| ×3 | 基準 × 3 | ¥3,000 |

#### カスタム入力

任意の金額を直接入力できます。

### 指値の動作

#### オークション開始前に設定した場合

- 商品がライブになった時点で **自動的に入札ON** になります
- 指値の範囲内であれば、価格上昇時も入札が継続されます
- 指値が2名以上ある場合は、入札開始待機中に **価格が自動調整** されます（詳細は後述）

#### ライブ中に設定した場合

- 現在価格 < 指値の場合：**即座に入札ON** になります
- 現在価格 ≥ 指値の場合：入札されません（設定のみ保存）
- 指値が2名以上になった場合：**即座に価格が自動調整** され、フリーズカウントダウンが開始されます
- **既に入札中のユーザーが指値を設定した場合** も、条件を満たせば価格調整が発生します

### 指値が発動するとき

現在価格が指値に達すると、以下が起こります。

1. **自動的に入札OFF** になります
2. 画面に **「上限価格に達したため自動的に入札オフになりました」** と通知が表示されます
3. 指値バッジがグレー（取り消し線付き）に変わります
4. LINE通知を設定している場合は通知が届きます

### 指値と自動離脱の関係

| 状態 | 価格上昇時の動作 |
|------|----------------|
| 指値あり・指値 > 新価格 | **入札継続**（自動離脱されない） |
| 指値あり・指値 ≤ 新価格 | **自動離脱**（指値発動） |
| 指値なし | **自動離脱**（再入札が必要） |

### 指値が2名以上ある場合の自動価格調整

オークション開始時・商品切替時・ライブ中の指値追加時に、指値が複数設定されていると価格が自動調整されます。

#### 基本ルール

1. **最低指値を超える次の上昇金額** まで価格が上昇します
2. 最低指値のユーザーは **指値発動で自動離脱** します
3. 2番目以降の指値ユーザーは **指値の範囲内であれば入札継続** します
4. 2番目の指値も超えてしまう場合は、2番目の指値を超えない最大の上昇金額に調整されます

#### 例1：異なる指値（A: ¥40,000 / B: ¥50,000）

1. 開始価格 ¥30,000
2. 価格が ¥41,000 に自動調整（¥40,000 を超える次の上昇金額）
3. Aさんの指値発動 → 自動離脱
4. Bさんが ¥41,000 で落札権利を持ってカウントダウン開始
5. 誰も入札しなければ → Bさんが ¥41,000 で落札

#### 例2：3名の指値（A: ¥30,000 / B: ¥50,000 / C: ¥80,000）

1. 開始価格 ¥20,000
2. 価格が ¥31,000 に自動調整
3. Aさんの指値発動 → 自動離脱
4. Bさん・Cさんが入札継続（指値がまだ有効なため保護）

#### 例3：指値が近い場合（A: ¥40,000 / B: ¥41,000、上昇幅 ¥2,000）

1. 開始価格 ¥30,000
2. ¥40,000 を超える次の上昇金額は ¥42,000 だが、Bの指値 ¥41,000 を超えてしまう
3. 価格は ¥41,000（Bの指値）に調整
4. Aさんの指値発動 → 自動離脱
5. Bさんが ¥41,000 で落札権利を持つ

#### 例4：同額の指値（A: ¥40,000 / B: ¥40,000）

1. 価格が ¥40,000 に調整（指値と同額）
2. **先に指値を設定した方** が保護されて入札継続
3. 後から設定した方は指値発動で自動離脱

#### 例5：ライブ中に指値が追加された場合

1. AとBが指値なしで入札中、現在価格 ¥10,000
2. Bが指値 ¥20,000 を設定 → Bは指値の範囲内で入札継続
3. Aが指値 ¥30,000 を設定 → 指値が2名以上になったため価格自動調整
4. 価格が ¥21,000 に調整（Bの指値を超える次の上昇金額）
5. Bの指値発動 → 自動離脱
6. Aが ¥21,000 で落札権利を持ってフリーズカウントダウン開始

### 指値の変更・解除

- **変更**: 指値ダイアログで新しい金額を入力して「設定する」
- **解除**: 指値ダイアログで「設定を解除」を押す
  - 解除すると入札からも離脱します

### 注意事項

- 指値は **1円以上** で設定してください
- 現在価格以下の指値を設定すると、即座に発動します（入札しません）
- 指値発動後に再度入札する場合は、指値を更新するか手動で入札してください
- 同額の指値が複数ある場合は、**先に設定した方が優先** されます

## 10. 落札と支払い

### 落札の確定

- カウントダウンが0になった時点で **入札者が1名のみ** の場合、その方が落札者です
- 落札時には画面に **お祝いオーバーレイ**（紙吹雪 + 「落札おめでとうございます！」）が約4秒間表示されます

### 流札（不成立）

- カウントダウンが0になった時点で **入札者が0名** の場合、その商品は流札（不成立）となります
- 流札後は自動的に次の商品に移ります

### 落札結果の確認

#### ライブ画面内

- 画面下部の **「あなたの落札一覧」** パネルに、落札した商品と合計金額が表示されます

#### オークション終了後

- 終了画面に落札結果の一覧が表示されます
- 「落札管理へ」ボタンから詳細を確認できます

### 落札管理画面

| 項目 | 内容 |
|------|------|
| 落札単価 | 1匹あたりの落札価格 |
| 数量 | 匹数 |
| 手数料 | 購入者手数料 |
| 合計金額（税込） | 落札単価 × 数量 + 手数料 |
| 支払い期限 | 支払い期限日時 |
| 支払い状況 | 支払い待ち → 入金確認済み |
| 配送状況 | 発送待ち → 配送中 → 配達完了 |

### 支払いの流れ

1. **支払い待ち**: 「請求書を確認・支払い」ボタンから支払い手続き
2. **入金確認済み**: 運営が入金を確認
3. **発送準備中**: 出品者が発送準備
4. **配送中**: 発送完了（伝票番号が表示されます）
5. **配達完了**: お届け完了

### 配送先の変更

- **入金確認前** であれば、配送先住所を変更できます
- 入金確認後は変更できません

## 13. よくある質問（FAQ）

### Q1. 入札ボタンが押せません

**A.** 以下のタイミングでは入札ボタンが無効になります。
- **入札開始待機中**（商品切り替え直後の約5秒間）
- **ブロック中**（価格上昇直後の約1秒間）

少し待ってから再度お試しください。

### Q2. 入札していたのに勝手に入札OFFになりました

**A.** 価格が上昇した際、落札権利者以外は自動的に入札OFFになります。これは正常な動作です。再度入札したい場合は「入札する」ボタンを押してください。指値を設定しておくと、指値の範囲内で自動的に入札が継続されます。

### Q3. 指値を設定しているのに離脱しました

**A.** 現在価格が指値に達した（または超えた）ため、指値が発動して自動離脱しました。より高い金額で入札を続けたい場合は、指値を更新するか、手動で入札してください。

### Q4. 画面が更新されません

**A.** 接続状態を確認してください。「ポーリング中」と表示されている場合、一時的に接続が不安定です。通常は自動で復旧しますが、改善しない場合はページを更新してください。

### Q5. 複数のレーンに同時に入札できますか？

**A.** はい、複数のレーンに同時に入札できます。ただし、各レーンの状況を把握しながら入札してください。

### Q6. 落札後のキャンセルはできますか？

**A.** 落札確定後のキャンセルはできません。入札は慎重に行ってください。予算を超えないよう、指値機能のご利用をおすすめします。

### Q7. 配送先を間違えました

**A.** 入金確認前であれば、落札管理画面から配送先を変更できます。入金確認後は変更できませんのでご注意ください。

### Q8. 「ブロック中」とは何ですか？

**A.** 価格が上昇した直後に表示される短い待機時間（約1秒）です。価格変動直後に誤ってボタンを押してしまうことを防ぐための仕組みです。ブロックが終わると自動的に入札可能になります。

### Q9. 指値はいつ設定するのがよいですか？

**A.** オークション開始前に設定しておくことをおすすめします。開始前に設定しておくと、商品がライブになった時点で自動的に入札ONになります。ライブ中でも設定・変更は可能です。

### Q10. 同じ価格で2人が入札したらどうなりますか？

**A.** 2人以上が同じ価格で入札中の場合、カウントダウン終了時に価格が1段階上昇します。最後に入札した人が落札権利者となり、それ以外の人は自動離脱されます。

### Q11. 同じ金額の指値を複数人が設定したらどうなりますか？

**A.** 同額の指値が複数ある場合、**先に指値を設定した方が優先** されます。先に設定した方がその金額で入札権利を保持し、後から設定した方は指値発動で自動離脱されます。

### Q12. ライブ中に指値を設定したら何が起きますか？

**A.** 現在価格より高い指値を設定すると即座に入札ONになります。その時点で指値が2名以上になった場合は、価格が自動調整されます。既に入札中の状態で指値を設定した場合も同様です。

### Q13. 指値を設定している人がいる時に手動で入札するとどうなりますか？

**A.** 手動入札すると価格は上昇しますが、指値ユーザーがいる場合は **指値が最も高い人が落札権利者** となります。手動入札者は価格上昇のたびに自動離脱されるため、毎回再入札が必要です。指値ユーザーの指値に到達するまでこの繰り返しとなります。

### Q14. 指値が高い人が常に落札権利者になるのですか？

**A.** はい。有効な指値（指値 > 現在価格）を持つユーザーがいる場合、**指値が最も高い人が落札権利者** を保持し続けます。手動入札者が入札しても、価格上昇後に指値最高者が落札権利者に戻ります。指値ユーザーが全員離脱した場合は、従来通り最後に入札した人が落札権利者となります。

### ユースケース16：指値1名のみの場合

> **状況**: Aさんだけが指値を設定している場合。

1. Aさんが **指値 ¥100,000** を設定
2. オークション開始 → Aさんが開始価格で自動入札ON
3. 価格調整は行われない（指値1名のみのため）
4. 通常のカウントダウン開始
5. 他に入札者がいなければ → Aさんが開始価格で **落札**
6. 他に入札者が現れた場合 → 通常の競り合い（Aさんは指値の範囲内で保護）

**ポイント**: 指値1名のみの場合は価格調整されず、開始価格からスタートします。

### ユースケース17：ブロック中の操作

> **状況**: 価格上昇直後のブロック（誤タップ防止）中の操作。

1. 価格が ¥5,000 → ¥5,500 に上昇
2. 即座にブロック（フリーズ）開始、ボタンがグレーに
3. 「ブロック中 1秒」と表示、円型プログレスバーが回転
4. この間に入札ボタンを押しても **反応しない**（誤操作防止）
5. ブロック終了 → ボタンが有効化
6. 入札カウントダウン（5秒）開始 → 入札可能に

**ポイント**: ブロックは短時間（約1秒）です。焦らず待ちましょう。

### ユースケース18：高額帯でのカウントダウン秒数変動

> **状況**: 価格が上がるにつれてカウントダウン秒数が変わる。

1. 開始価格 ¥1,000（低価格帯：カウントダウン3秒、ブロック0.5秒）
2. 競り合いで ¥5,000 に到達（中価格帯：カウントダウン5秒、ブロック1秒）
3. さらに ¥50,000 に到達（高価格帯：カウントダウン8秒、ブロック2秒）
4. 高額になるほど考える時間が長くなる

**ポイント**: 高額帯では判断時間が長くなるので、落ち着いて入札できます。

### ユースケース19：お気に入り商品の順番接近通知

> **状況**: お気に入りに登録した商品の順番が近づいた。

1. 出品一覧で気になる商品をお気に入りに登録
2. オークション進行中、お気に入り商品の5つ前の商品が競られ始める
3. LINE通知で「お気に入りの商品の順番が近づいています」と通知
4. オークション画面を開いて待機
5. お気に入り商品がライブになったら入札

**ポイント**: お気に入りとLINE通知を組み合わせると、見逃しを防げます。

### ユースケース20：オークション一時停止と再開

> **状況**: 運営がオークションを一時停止した場合。

1. オークション進行中、運営側の判断で一時停止
2. 全レーンのカウントダウンが停止
3. 画面に「一時停止中」と表示される
4. 入札ボタンは無効化（操作不可）
5. 運営が再開 → カウントダウンが再開
6. 停止前の状態から続行（入札状態は保持）

**ポイント**: 一時停止中は何も操作できませんが、入札状態は保持されています。

### ユースケース21：指値を途中で引き上げる

> **状況**: 競り合いの中で指値を引き上げたい場合。

1. Aさんが **指値 ¥30,000** で自動入札中
2. 価格が ¥28,000 まで上昇、もう少しで指値に到達
3. 「もっと高くても欲しい」と判断
4. 指値ダイアログを開いて **¥50,000** に変更
5. 指値が更新され、¥50,000 まで自動入札が継続
6. 価格が ¥30,000 を超えても離脱されない

**ポイント**: 指値はいつでも変更可能です。競り合いの状況を見て判断しましょう。

### ユースケース22：指値を解除して手動入札に切り替え

> **状況**: 指値を解除して自分のペースで入札したい場合。

1. Aさんが **指値 ¥20,000** で自動入札中
2. 「自分で判断して入札したい」と思い、指値を解除
3. 指値ダイアログで「設定を解除」を押す
4. **入札からも離脱** される（指値解除 = 入札OFF）
5. 改めて「入札する」ボタンで手動入札
6. 以降は価格上昇のたびに手動で再入札が必要

**ポイント**: 指値を解除すると入札からも離脱されるので注意してください。

### ユースケース23：開始価格が高い商品への入札

> **状況**: 開始価格 ¥50,000 の高額商品。

1. レーンカードに開始価格 ¥50,000 と表示
2. 高価格帯のため上昇幅は +¥5,000
3. 入札カウントダウンは8秒（高額帯設定）
4. Aさんが入札 → Bさんも入札 → ¥55,000 に上昇
5. ブロック2秒 → カウントダウン8秒
6. 慎重に判断する時間がある

**ポイント**: 高額商品はカウントダウンが長めに設定されていることが多いです。

### ユースケース24：全レーンが終了してオークション自動終了

> **状況**: 全てのレーンの商品が終了。

1. レーン1：最後の商品が落札 → レーン1終了（「全出品終了」表示）
2. レーン2：最後の商品が流札 → レーン2終了
3. レーン3：最後の商品が落札 → レーン3終了
4. 全レーン終了 → **オークションが自動的に終了**
5. 画面に「すべての出品が終了しました」と表示
6. 終了画面に遷移、落札結果の一覧が表示

**ポイント**: 全レーンが終了すると自動的にオークションが終了します。

### ユースケース25：複数商品を落札した場合の合計確認

> **状況**: 1回のオークションで3つの商品を落札。

1. レーン1で「紅白ラメ」を ¥3,000 で落札
2. レーン2で「幹之フルボディ」を ¥5,000 で落札
3. レーン3で「楊貴妃」を ¥2,000 で落札
4. 画面下部の「あなたの落札一覧」に3件表示
5. 合計金額（手数料込み）が表示される
6. オークション終了後、落札管理画面で一括確認
7. 各商品ごとに支払い手続き

**ポイント**: 複数落札した場合は合計金額を確認して予算管理しましょう。

### ユースケース26：入札者0名で商品が次々と流札

> **状況**: 人気のない商品が続いて流札。

1. レーン1の商品、入札者0名 → カウントダウン終了 → 流札
2. 自動的に次の商品に切り替わる（約5秒の待機）
3. 次の商品も入札者0名 → 流札
4. さらに次の商品に切り替わる
5. 気になる商品が来たら「入札する」ボタンで参加

**ポイント**: 流札が続いても焦る必要はありません。欲しい商品を待ちましょう。

### ユースケース27：指値と手動入札の併用

> **状況**: 指値を設定しつつ、状況を見て手動でも操作。

1. Aさんが **指値 ¥30,000** を設定して自動入札中
2. 価格が ¥25,000 まで上昇
3. 競合相手が離脱し、Aさん1名のみに
4. カウントダウン終了 → Aさんが ¥25,000 で **落札**
5. 指値 ¥30,000 を設定していたが、実際の落札価格は ¥25,000

**ポイント**: 指値は「上限」です。実際の落札価格は競合状況により指値より低くなることが多いです。

### ユースケース28：商品詳細を確認してから入札

> **状況**: 商品の詳細情報を確認してから入札判断。

1. レーンカードの情報アイコン（ℹ️）を押す
2. 商品詳細ダイアログが開く
3. メディアギャラリーで商品画像・動画を確認
4. 品種情報、出品者情報、数量を確認
5. ダイアログを閉じる
6. 入札するかどうかを判断して操作

**ポイント**: 入札前に商品詳細を確認することをおすすめします。

### ユースケース29：指値が2名で開始、途中から手動参加者が加わる

> **状況**: A（¥40,000）とB（¥60,000）が指値設定済み、Cが途中参加。

1. オークション開始、開始価格 ¥30,000
2. 価格が ¥41,000 に自動調整 → Aの指値発動、離脱
3. Bが ¥41,000 で落札権利を持つ（指値最高者）
4. カウントダウン中にCさんが手動で入札
5. 即座に ¥42,000 に上昇
6. **Bが落札権利者を維持**（指値最高者のため）、Cは **自動離脱**
7. Cが再入札 → ¥43,000 に上昇
8. **Bが落札権利者を維持**、Cは再び自動離脱
9. ...繰り返し...
10. ¥60,000 に到達 → Bの指値発動、自動離脱
11. Cが入札中なら → Cが ¥60,000 で **落札**

**ポイント**: 指値が高い人が落札権利者を保持し続けます。手動入札者は毎回再入札が必要です。

### ユースケース30：オークション終了直前の駆け込み入札

> **状況**: カウントダウン残り1秒で入札。

1. 現在価格 ¥10,000、Aさんが入札中
2. カウントダウン残り1秒
3. Bさんが「入札する」ボタンを押す
4. 即座に ¥11,000 に上昇、ブロック開始
5. カウントダウンがリセット（ブロック → 新しいカウントダウン）
6. Aさんは自動離脱
7. Aさんが再入札するかどうかの判断時間が与えられる

**ポイント**: カウントダウン終了直前でも入札可能です。入札があれば価格上昇してカウントダウンがリセットされます。

## 付録：用語集

| 用語 | 説明 |
|------|------|
| レーン | 同時に進行する競りの列。複数レーンで同時に異なる商品が競られます |
| カウントダウン | 入札の残り時間。0になると結果が確定します |
| ブロック（フリーズ） | 価格上昇直後の短い待機時間。誤タップ防止のためです |
| 入札開始待機（pre_bid） | 商品切り替え直後の待機時間。商品情報を確認する時間です |
| 指値（さしね） | 上限価格。この価格まで自動で入札が継続されます |
| 落札権利 | 入札中の状態。カウントダウン終了時に1名のみなら落札確定。指値最高者がいれば指値最高者が保持 |
| 自動離脱 | 価格上昇時に、指値ユーザー以外（または指値発動者）が自動的に入札OFFになること |
| 流札（りゅうさつ） | 入札者がいない状態でカウントダウンが終了し、不成立になること |
| プレミアム | 特に注目度の高い商品に付けられるラベル |
| 上昇幅 | 価格が上がる際の1回あたりの金額。価格帯により異なります |
| 価格自動調整 | 指値が2名以上ある場合に、システムが自動で価格を調整する仕組み |
| 先着優先 | 同額の指値が複数ある場合、先に設定した方が優先されるルール |
