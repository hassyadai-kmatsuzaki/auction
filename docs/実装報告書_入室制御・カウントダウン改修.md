# 実装報告書: 会場入室制御・生体切り替えカウントダウン・動的カウントダウン秒数

**作成日**: 2026年2月9日  
**対象機能**: 会場入室時刻の制御 / 生体切り替え時の入札開始待機 / 入札者数に応じた動的カウントダウン秒数

---

## 1. 実装概要

### 1-1. 会場入室時刻の制御
オークション開始時刻の一定時間前（デフォルト30分）から参加者が会場（ライブ画面）に入室できるよう制御を実装。

### 1-2. 生体切り替え時の入札開始待機
レーンで次の生体に切り替わった際、参加者が新しい生体を確認する時間を確保するため、入札開始前にカウントダウン待機（デフォルト5秒）を実装。

### 1-3. 入札者数に応じた動的カウントダウン秒数
入札者数に応じてカウントダウン秒数を動的に切り替える機能を実装。

| 状態 | カウントダウン秒数 | 備考 |
|------|-------------------|------|
| 商品開始時（入札者0人） | 通常（10秒） | 参加者の入札判断時間を確保 |
| 入札者が1人の場合 | 通常（10秒） | 他の参加者の入札参加を待つ |
| 入札者が2人以上の場合 | 競合（1秒） | テンポ良く価格が上昇 |
| 入札者が2人→1人に減った場合 | 通常（10秒）に戻る | カウントダウンが自動延長される |

## 4. 動的カウントダウンの詳細動作フロー

```
商品表示
  │
  ├── [item_switch_delay_seconds > 0 の場合]
  │     └── pre_bid フェーズ（入札開始待機）
  │           └── 「入札開始まで ○秒」表示、入札ボタン無効
  │
  └── bidding フェーズ開始（カウントダウン = countdown_seconds_default）
        │
        ├── 入札者 0〜1人のまま → countdown_seconds_default でカウント
        │     └── 0到達 → 流札 or 落札 → 次の商品
        │
        └── 入札者 2人以上になった
              │
              ├── ★ モード切替: countdown を countdown_seconds_competitive にリセット
              │
              └── 競合モードでカウント
                    │
                    ├── 0到達（2人以上継続）→ 価格上昇 → countdown_seconds_competitive にリセット
                    │
                    └── 途中で入札者が1人以下になった
                          └── ★ モード切替: countdown を countdown_seconds_default にリセット
                                └── 0到達 → 落札 → 次の商品
```

### 具体例（デフォルト設定：通常10秒、競合1秒）

```
1. 商品表示 → 入札開始待機5秒 → 入札開始（10秒カウントダウン）
2. 残り7秒の時にAさんが入札（1人、通常モード継続）
3. 残り4秒の時にBさんが入札（2人に → ★競合モード：1秒にリセット）
4. 残り1秒→0秒: 2人以上 → 価格上昇、1秒にリセット
5. Cさんも入札（3人、競合モード継続）
6. 0秒到達: 3人 → 価格上昇、1秒にリセット
7. BさんとCさんが離脱（1人に → ★通常モード：10秒にリセット）
8. 10秒カウントダウン...
9. 0秒到達: 1人 → Aさんが落札！
```

## 6. 入札開始待機の詳細動作

### バックエンドフロー
1. `moveToNextItem()` / `nextItem()` で新商品に切り替え
2. `startPreBidCountdown()` を呼び出し
3. `item_switch_delay_seconds` が 0 なら即 `startCountdown()`
4. 0 より大きい場合、`phase: 'pre_bid'` でキャッシュ保存
5. 毎秒 `tickPreBid()` でカウントダウン
6. 0到達で `phase: 'bidding'` に移行、通常カウントダウン開始

### フロントエンド表示
- **pre_bidフェーズ**: 「入札開始まで ○秒」表示、入札ボタンは「入札準備中...」で無効
- **biddingフェーズ移行後**: 通常の入札画面に切り替わり

## 9. テスト観点

### 動的カウントダウンのテストシナリオ

1. **基本フロー**: 商品開始 → 10秒カウント → 0到達（入札者0人） → 流札
2. **1人入札**: 商品開始 → 10秒カウント → 途中で1人入札 → 10秒のまま → 0到達 → 落札
3. **競合発生**: 商品開始 → 10秒 → 2人入札 → 1秒にリセット → 0到達 → 価格上昇 → 1秒リセット
4. **競合→通常**: 2人入札中（1秒） → 1人離脱 → 10秒にリセット → 0到達 → 落札
5. **入札開始待機**: 商品切替 → 5秒待機 → 10秒カウント開始
6. **入室不可**: 開始1時間前にアクセス → 入室不可画面 → 30分前に自動遷移
7. **設定変更**: システム設定で秒数変更 → 次の商品から反映
8. **カスタム設定**: オークション個別に通常20秒/競合3秒 → 該当オークションで反映
