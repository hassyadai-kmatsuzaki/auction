# お知らせ管理機能 実装仕様書

## 1. 概要

メダカオークションシステムのお知らせ管理機能の実装仕様書です。
管理者がユーザーに向けてお知らせを作成・公開・管理する機能を提供します。

---

## 2. 機能要件

### 2.1 お知らせ作成機能

#### 基本情報
- **タイトル**: 必須、最大200文字
- **本文**: 必須、テキスト形式（将来的に画像対応予定）
- **対象ユーザー**: 必須、複数選択可
  - 管理者
  - 出品者
  - 参加者

#### 公開設定
- **公開ステータス**:
  - `draft`: 下書き
  - `scheduled`: 公開予約
  - `published`: 公開中
  - `hidden`: 非表示
  - `deleted`: 削除済み（論理削除）

- **公開タイミング**:
  - すぐに公開: `published_at`に現在時刻を設定
  - 公開予約: `published_at`に未来の日時を設定

#### 重要度設定
- **通常**: デフォルト
- **重要**: リスト上部に固定表示、目立つデザイン

### 2.2 お知らせ編集機能

#### 編集可能条件
- ステータスが`draft`または`scheduled`の場合のみ編集可能
- ステータスが`published`の場合は編集不可
  - ただし、`hidden`への変更は可能

#### 編集可能項目（下書き・予約中のみ）
- タイトル
- 本文
- 対象ユーザー
- 公開日時
- 重要度

#### 編集不可だが変更可能な項目（公開後）
- ステータス（`published` → `hidden` のみ）

### 2.3 お知らせ削除機能

#### 論理削除
- ステータスを`deleted`に変更
- `deleted_at`に削除日時を記録
- 削除者のIDを記録
- 実際のデータは保持（監査目的）

#### 削除可能条件
- 全てのステータスで削除可能
- 公開中のお知らせも削除可能

### 2.4 お知らせ一覧機能

#### 管理画面（管理者用）
- **表示項目**:
  - ID
  - タイトル
  - 対象ユーザー（バッジ表示）
  - ステータス
  - 重要度
  - 公開日時
  - 作成者
  - 更新日時
  - 操作ボタン

- **フィルター**:
  - ステータス（全て/下書き/公開予約/公開中/非表示）
  - 対象ユーザー（全て/管理者/出品者/参加者）
  - 重要度（全て/通常/重要）

- **ソート**:
  - 公開日時（降順/昇順）
  - 作成日時（降順/昇順）
  - 更新日時（降順/昇順）

- **検索**:
  - タイトル・本文の全文検索

#### ユーザー画面（参加者・出品者用）
- **表示条件**:
  - ステータスが`published`
  - `published_at`が現在時刻以前
  - 自分のロールが対象に含まれている
  - `deleted_at`がNULL

- **表示順**:
  1. 重要なお知らせ（`is_important = true`）を上位に表示
  2. 公開日時の降順

- **表示項目**:
  - タイトル
  - 本文
  - 公開日時
  - 重要マーク

## 3. データベース設計

### 3.1 テーブル: `announcements`

| カラム名 | 型 | NULL | デフォルト | 説明 |
|---------|-----|------|-----------|------|
| id | BIGINT UNSIGNED | NO | AUTO_INCREMENT | お知らせID |
| title | VARCHAR(200) | NO | - | タイトル |
| content | TEXT | NO | - | 本文 |
| status | ENUM | NO | 'draft' | ステータス |
| target_roles | JSON | NO | - | 対象ロール（配列） |
| is_important | BOOLEAN | NO | false | 重要フラグ |
| published_at | TIMESTAMP | YES | NULL | 公開日時 |
| created_by | BIGINT UNSIGNED | NO | - | 作成者ID |
| updated_by | BIGINT UNSIGNED | YES | NULL | 更新者ID |
| deleted_at | TIMESTAMP | YES | NULL | 削除日時 |
| deleted_by | BIGINT UNSIGNED | YES | NULL | 削除者ID |
| created_at | TIMESTAMP | NO | CURRENT_TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | NO | CURRENT_TIMESTAMP | 更新日時 |

#### インデックス
- PRIMARY KEY: `id`
- INDEX: `idx_status` (`status`)
- INDEX: `idx_published_at` (`published_at`)
- INDEX: `idx_created_by` (`created_by`)
- INDEX: `idx_deleted_at` (`deleted_at`)

#### 外部キー制約
- `created_by` → `users(id)`
- `updated_by` → `users(id)`
- `deleted_by` → `users(id)`

#### status ENUM値
- `draft`: 下書き
- `scheduled`: 公開予約
- `published`: 公開中
- `hidden`: 非表示

#### target_roles JSON構造
```json
["admin", "seller", "participant"]
```

## 5. ビジネスロジック

### 5.1 公開ステータスの自動更新

#### スケジュール公開の処理
- 定期的（1分ごと）に以下のクエリを実行:
  ```sql
  UPDATE announcements
  SET status = 'published'
  WHERE status = 'scheduled'
    AND published_at <= NOW()
    AND deleted_at IS NULL;
  ```

- 実装方法: Laravel Schedulerを使用
- コマンド: `php artisan announcements:publish-scheduled`

### 5.2 編集可否の判定ロジック

```php
public function canEdit(): bool
{
    return in_array($this->status, ['draft', 'scheduled']);
}

public function canChangeStatus(): bool
{
    // 公開済みの場合は非表示のみ可能
    if ($this->status === 'published') {
        return true; // hidden への変更のみ許可
    }
    return true;
}

public function canDelete(): bool
{
    return $this->deleted_at === null;
}
```

### 5.3 対象ユーザーの判定ロジック

```php
public function isTargetedTo(string $role): bool
{
    return in_array($role, $this->target_roles);
}

public function isVisibleToUser(User $user): bool
{
    // 公開中かつ公開日時を過ぎている
    if ($this->status !== 'published') {
        return false;
    }
    
    if ($this->published_at > now()) {
        return false;
    }
    
    // 削除されていない
    if ($this->deleted_at !== null) {
        return false;
    }
    
    // ユーザーのロールが対象に含まれている
    foreach ($user->roles as $role) {
        if ($this->isTargetedTo($role->name)) {
            return true;
        }
    }
    
    return false;
}
```

#### 6.1.2 お知らせ作成ページ (`/admin/announcements/create`)
- **レイアウト**: AdminLayout
- **コンポーネント**: AnnouncementForm.tsx

**フォーム項目**:
- タイトル（必須）
- 本文（必須、テキストエリア）
- 対象ユーザー（必須、複数選択チェックボックス）
- 重要度（チェックボックス）
- 公開タイミング（ラジオボタン）
  - すぐに公開
  - 公開日時を指定
- 公開日時（DateTimePicker、公開日時指定の場合のみ表示）

**ボタン**:
- 下書き保存
- プレビュー
- 公開（またはスケジュール）
- キャンセル

#### 6.1.3 お知らせ編集ページ (`/admin/announcements/:id/edit`)
- **レイアウト**: AdminLayout
- **コンポーネント**: AnnouncementForm.tsx（作成と共通）

**表示制御**:
- 公開済みの場合、編集フォームを表示せず、非表示ボタンのみ表示
- 下書き・予約中の場合、通常通り編集可能

#### 6.1.4 お知らせプレビューダイアログ
- **コンポーネント**: AnnouncementPreview.tsx

**表示内容**:
- タイトル
- 本文（整形済み）
- 重要マーク
- 公開日時
- 対象ユーザー
