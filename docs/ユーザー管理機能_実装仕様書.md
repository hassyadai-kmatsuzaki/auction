# ユーザー管理機能 実装仕様書

## 📅 作成日：2026年1月16日

---

## 🎯 機能概要

管理者がシステムのユーザーを管理できる機能です。ユーザーの作成、閲覧、編集、承認/拒否、権限付与などを行います。

---

## 📋 機能一覧

### 1. ユーザー一覧表示
- ユーザーの一覧を表示
- 検索・フィルタリング機能
- ページネーション

### 2. ユーザー詳細表示
- ユーザーの詳細情報を表示
- ロール情報
- 出品者プロフィール（出品者の場合）
- 承認/拒否履歴

### 3. ユーザー作成
- 新規ユーザーの作成
- ロールの選択（複数可）
- パスワード設定用メール送信

### 4. ユーザー編集
- ユーザー情報の更新
- ロールの変更
- 住所情報の更新

### 5. ユーザーステータス管理
- 承認（pending → approved）
- 拒否（pending → rejected）
- 停止（approved → suspended）
- 無効化（is_active を false に）

```
│                                          │
│           [キャンセル]  [作成]            │
└─────────────────────────────────────────┘
```

#### 入力項目
- **必須項目**:
  - 名前
  - メールアドレス
  - ロール（最低1つ）

- **任意項目**:
  - 電話番号
  - 住所情報（郵便番号、都道府県、市区町村、住所1、住所2）

#### バリデーション
- 名前: 必須、255文字以内
- メールアドレス: 必須、メール形式、重複チェック
- ロール: 最低1つ選択必須

#### 作成後の動作
1. ユーザーをデータベースに登録（status: pending）
2. パスワード設定用のトークンを生成
3. ユーザーにパスワード設定メールを送信
4. 成功メッセージを表示
5. ユーザー一覧に戻る

## 💾 データベース設計

### users テーブル

既存のテーブルを使用。主要なカラム：

- `id`: ユーザーID
- `name`: 名前
- `email`: メールアドレス
- `password`: パスワード（ハッシュ化）
- `phone`: 電話番号
- `postal_code`: 郵便番号
- `prefecture`: 都道府県
- `city`: 市区町村
- `address_line1`: 住所1
- `address_line2`: 住所2
- `status`: ステータス（pending, approved, suspended, rejected）
- `is_active`: 有効/無効
- `email_verified_at`: メール確認日時
- `approved_at`: 承認日時
- `approved_by`: 承認者ID
- `rejected_at`: 拒否日時
- `rejected_by`: 拒否者ID
- `rejection_reason`: 拒否理由
- `last_login_at`: 最終ログイン日時

### user_roles テーブル

- `user_id`: ユーザーID
- `role_id`: ロールID
- `assigned_at`: 付与日時
- `assigned_by`: 付与者ID

## 📱 レスポンシブ対応

### デスクトップ（1200px以上）
- 全カラムを表示
- 横スクロールなし

### タブレット（768px - 1199px）
- 重要なカラムのみ表示
- 詳細は詳細画面で確認

### モバイル（767px以下）
- カード形式で表示
- 縦スクロール

## 🔒 権限管理

### アクセス権限
- **管理者（admin）のみ**がユーザー管理機能にアクセス可能
- `CheckRole` ミドルウェアで制御

### 操作権限
- **ユーザー作成**: 管理者
- **ユーザー編集**: 管理者
- **ステータス変更**: 管理者
- **ロール変更**: 管理者
- **削除**: 管理者（ただし、最後の管理者は削除不可）
