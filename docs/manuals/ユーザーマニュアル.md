## 1. はじめに

**メダカオークション**は、メダカ業界初のオンライン専門オークションプラットフォームです。  
全国のブリーダー・愛好家が場所を問わずリアルタイムで取引に参加できます。

### 対応ブラウザ

| ブラウザ | バージョン |
|---|---|
| Google Chrome | 最新版推奨 |
| Safari | 最新版推奨（iOS 対応） |
| Firefox | 最新版 |
| Edge | 最新版 |

### ロールと権限

| ロール | できること |
|---|---|
| **参加者（買受者）** | オークション参加・入札・落札商品管理 |
| **出品者** | 商品出品・発送管理・精算確認 |
| **管理者** | システム全体の管理・ライブ運営・CSV エクスポート |
| **メディア編集者** | 開催前オークションの商品写真／動画の編集のみ可能（admin 兼任可） |

## 2. アカウント登録・ログイン

### 2.1 新規会員登録

1. トップページの「**新規登録**」をクリック
2. 以下の情報を入力して「登録」をクリック
   - 氏名、メールアドレス
   - 電話番号
   - 住所（郵便番号・都道府県・市区町村・番地）
3. **管理者による審査・承認**をお待ちください（通常1〜2営業日）
4. 承認後、登録メールアドレスに「パスワード設定メール」が届きます
5. メール内のリンクからパスワードを設定してください（有効期限: 24時間）
6. パスワード設定完了後、ログインできるようになります

> ⚠️ パスワードは8文字以上で、英大文字・小文字・数字の組み合わせを推奨します。

### 2.2 Google アカウントでの登録・ログイン

1. ログイン画面の「**Google でログイン**」をクリック
2. Google アカウントを選択して認証
3. 初回は管理者の承認が必要です（メール通知後にログイン可能）

### 2.3 ログイン

1. メールアドレス・パスワードを入力して「**ログイン**」をクリック
2. 二段階認証（2FA）を設定している場合: 認証アプリの6桁のコードを入力

### 2.4 パスワードを忘れた場合

1. ログイン画面の「**パスワードをお忘れの方**」をクリック
2. 登録済みのメールアドレスを入力
3. パスワードリセットリンクがメールで届きます（有効期限: 60分）
4. リンクから新しいパスワードを設定

## 3. 参加者向けガイド

### 3.1 年会費プランへの加入

オークションに入札するには、**bid プラン（参加者向け）**への加入が必要です。

1. マイページ → 「**サブスクリプション**」
2. プランを選択して「加入する」をクリック
3. クレジットカード情報を入力（Square 決済）
4. 加入完了後、即時に入札機能が利用可能になります

### 3.2 オークションへの参加

1. **ホーム画面**: 開催中・開催予定のオークション一覧を確認
2. 参加したいオークションをクリック
3. **3レーン分割画面**が表示されます（同時に最大3商品が進行中）

#### オークション画面の見方

```
┌──────────────┬──────────────┬──────────────┐
│   レーン 1   │   レーン 2   │   レーン 3   │
│              │              │              │
│ [商品画像]   │ [商品画像]   │ [商品画像]   │
│              │              │              │
│ 品種名       │ 品種名       │ 品種名       │
│ 現在価格     │ 現在価格     │ 現在価格     │
│ 参加者数     │ 参加者数     │ 参加者数     │
│ カウント     │ カウント     │ カウント     │
│ [入札ボタン] │ [入札ボタン] │ [入札ボタン] │
└──────────────┴──────────────┴──────────────┘
```

### 3.3 入札の仕組み

本オークションは**最後の1人**形式です。

1. 「**入札**」ボタンをクリックして入札参加
   - ボタンが**緑色** = 現在入札中
   - ボタンが**灰色** = 未参加
2. 参加者が1人になるとカウントダウン開始
3. **カウントダウンが0になった時点で入札中のユーザーが落札**
4. 新たな入札参加者が現れると、カウントダウンがリセットされます

> 💡 **入札ボタンの再クリックで離脱**できます。買いすぎ防止にご活用ください。

### 3.4 指値（上限価格）の設定

予算オーバーを防ぐための**自動離脱機能**です。

1. 商品の「**指値**」ボタンをクリック
2. 上限価格（円）を入力して「設定」
3. 現在価格が指値に達すると**自動的に入札から離脱**します
4. 指値はいつでも変更・削除可能です

> ⚠️ 指値を設定しても、価格が指値を超える前に落札される場合もあります。

### 3.5 お気に入り機能

気になる商品をウォッチリストに登録できます。

1. 商品カードのハートアイコン（♡）をクリック
2. お気に入り登録済みの商品は「お気に入り一覧」で確認可能
3. 登録商品の出番が近づくと**メール・LINE で通知**が届きます

### 3.6 商品検索・フィルタ

- **キーワード検索**: 品種名で検索
- **フィルタ項目**:
  - 開催オークション
  - 出品者
  - 価格帯（最低〜最高）
  - 性別（オス / メス / ペア / 不明）
  - 並び順（価格安い順 / 高い順 / 人気順）

#### 検索条件の保存

フィルタ設定後「**条件を保存**」をクリックすると、次回以降ワンクリックで同じ条件を適用できます。

### 3.7 落札後の流れ

```
落札通知（メール・LINE）
    ↓
マイページ → 落札商品一覧で確認
    ↓
配送先住所の確認・更新
    ↓
請求書ダウンロード（PDF）
    ↓
振込入金（指定口座へ）
    ↓
管理者が入金確認
    ↓
出品者が梱包・発送
    ↓
追跡番号通知（メール・LINE）
    ↓
商品受取
    ↓
取引評価の投稿
```

### 3.8 配送先住所の設定

1. マイページ → 「**落札商品**」→ 対象のオークションをクリック
2. 「**配送先を変更**」をクリック
3. 宛名・住所を入力して保存
4. 配送料が自動計算されます（袋のサイズ・匹数・配送先に基づく）

> ⚠️ 配送先の変更は発送処理前まで可能です。

### 3.9 配送状況の確認

1. マイページ → 「**落札商品**」
2. 追跡番号が表示されたらクリック
3. ヤマト運輸・佐川急便の追跡ページに遷移します

### 3.10 取引評価

取引完了後、相手への評価を投稿してください。

1. 落札商品詳細 → 「**評価する**」
2. 星評価（1〜5）とコメントを入力
3. 「送信」をクリック

> ℹ️ 評価は取引ごとに1回のみ投稿可能です。

### 3.11 AIレコメンド

過去の閲覧・入札履歴に基づいた「**おすすめ商品**」がホーム画面に表示されます。  
好みの品種をお気に入り登録すると、レコメンドの精度が向上します。

## 4. 出品者向けガイド

### 4.1 出品者プランへの加入

商品を出品するには、**sell プラン（出品者向け）**への加入が必要です。

1. マイページ → 「**サブスクリプション**」
2. sell プランを選択して加入

### 4.2 出品者プロフィールの設定

1. 出品者メニュー → 「**プロフィール設定**」
2. 以下を入力・更新してください

| 項目 | 内容 |
|---|---|
| 出品者名（表示名） | 参加者に見える名前 |
| 事業形態 | 個人 / 法人 |
| SNS リンク | Instagram / Twitter / YouTube 等 |
| 振込口座 | 精算振込先の口座情報 |

### 4.3 商品の出品

1. 出品者メニュー → 「**商品を出品**」
2. 以下の情報を入力

| 項目 | 必須 | 説明 |
|---|---|---|
| 品種名 | ✓ | 例: 三色透明鱗ラメ |
| 匹数 | ✓ | 出品する匹数 |
| 開始価格 | ✓ | 入札スタート価格（円） |
| 性別 | — | オス / メス / ペア / 不明 |
| 検品情報 | — | 状態・健康状態など |
| 個体情報 | — | 体型・色彩・特徴など |
| 親魚情報 | — | 血統情報 |
| 備考 | — | 購入者へのメッセージ |

3. **写真をアップロード**（最大10枚）
   - 上見・横見の写真を推奨します
   - 各写真は自動的に最適化されます
4. **動画をアップロード**（最大3分、任意）
5. 出品するオークションを選択して「**出品する**」をクリック

### 4.4 商品の一括登録（CSV）

多数の商品を一度に登録する場合は CSV インポートを使用します。

1. 出品者メニュー → 「**CSV テンプレートをダウンロード**」
2. テンプレートに商品情報を入力して保存
3. 「**CSV インポート**」からファイルをアップロード

### 4.5 発送管理

1. 落札確定後、「**発送管理**」画面に表示されます
2. 梱包して配送業者（ヤマト運輸・佐川急便）に発送
3. 「**発送処理**」をクリックして追跡番号を入力
4. 買受者に自動で追跡番号通知が送られます

> ⚠️ 発送期限（落札から指定日数以内）を守ってください。

### 4.6 売上・精算の確認

1. 出品者メニュー → 「**精算管理**」
2. オークションごとの売上を確認

| 項目 | 説明 |
|---|---|
| 総売上 | 落札価格の合計 |
| 手数料 | 設定された手数料率 × 総売上 |
| 配送料 | 買受者負担（精算対象外） |
| 精算額 | 総売上 - 手数料 = 振込予定額 |

3. **支払通知書 PDF** をダウンロードできます
4. 精算スケジュールに従って指定口座に振込が行われます

## 5. 管理者向けガイド

### 5.1 ユーザー管理

| 操作 | 手順 |
|---|---|
| ユーザー承認 | 管理 → ユーザー一覧 → 詳細 → 「承認」ボタン |
| ユーザー拒否 | 詳細 → 「拒否」→ 拒否理由を入力 |
| ロール変更 | 詳細 → ロール設定 |
| ユーザー停止 | is_active = false に設定 |

### 5.2 オークション管理

**オークション作成手順**

1. 管理 → オークション → 「**新規作成**」
2. 開催日時・レーン数・入札単位・カウントダウン秒数を設定
3. 商品をオークションに登録（直接入力 or CSV インポート）
4. レーンへの商品割当（手動 or 自動割当）
5. 出品者の進行順序を設定

**ライブ管理**

| ボタン | 動作 |
|---|---|
| 入場開放 | 参加者がオークション画面に入れるようになる |
| ライブ開始 | カウントダウン・入札が可能になる |
| 一時停止 | カウントダウン停止 |
| 再開 | カウントダウン再開 |
| 次の商品 | レーンを次の商品に進める |
| 終了 | オークション終了・落札処理 |

### 5.3 AI 機能の活用

| 機能 | 用途 | 操作 |
|---|---|---|
| 画像 AI 解析 | 商品品質スコア・品種判定 | AI → 画像解析 → 対象商品を選択 |
| 価格予測 | 参考開始価格の提示 | AI → 価格予測 → 対象商品を選択 |
| 不正検知 | 異常な入札パターンの検出 | AI → 不正検知 → オークション選択 |
| レコメンド | 参加者向けおすすめ商品生成 | AI → レコメンド生成 |

### 5.4 エスクロー管理

入金が確認された後の資金はエスクローで保護されます。

| ステータス | 意味 | 次のアクション |
|---|---|---|
| awaiting_payment | 入金待ち | — |
| payment_held | 入金済み・保管中 | 取引完了後にリリース |
| released_to_seller | 出品者へ送金済み | — |
| refunded | 返金済み | — |
| disputed | 紛争中 | 管理者が調査・判断 |

### 5.5 レポート

- **週次レポート**: 毎週月曜 09:00 に自動生成（管理 → レポート → 週次）
- **月次レポート**: 毎月1日 09:00 に自動生成（管理 → レポート → 月次）
- **手動生成**: レポート画面 → 「レポート生成」ボタン

### 5.6 CSV エクスポート

サイドメニュー「**CSV エクスポート**」（/admin/exports）から各種データを CSV ダウンロードできます。すべて BOM 付き UTF-8 で Excel 直接オープン可能。

| エクスポート | 内容 | 絞り込み |
|---|---|---|
| オークション一覧サマリー | 1行=1オークション。売上／会員数／送料／税金／出品数／出品人数／落札数／落札人数／手数料／参加数／開催日 | 開催日 From-To、テストオークションを含めるか |
| 出品生体明細 | 全出品（未落札含む）。落札者名・落札金額・送料・手数料・税金は落札済み行のみ埋まる | オークション単体 or 開催日 From-To、テスト含むか |
| 会員情報 | 全ユーザー1行。氏名／屋号／連絡先／ロール／登録日 | フィルタなし（全件） |
| 年会費サブスクリプション | 全ユーザー1行。登録状況／プラン名／年会費／サブスク状態／現在の課金期間終了／最終支払日 | フィルタなし（全件） |

**金額の集計仕様**

- 売上・手数料・送料は **落札成立全件** の合算（`won_items`、支払い状況不問）。
- 税金は `(売上 + 手数料 + 送料) × tax_rate / 100`。`tax_rate` は「設定」→「システム設定」で変更可能。
- 出品者名・落札者名は `屋号 → 氏名 → -` の順でフォールバック。
- テストオークション（`is_test=true`）はデフォルト除外。スイッチで含められる。

### 5.7 メディア編集者ロール

「**メディア編集者**」ロールはオークションの**写真／動画のみ**を編集できる権限です。

- アクセス可能: `/admin/media-editor` 配下
- 操作対象: ステータスが `preparing` または `scheduled` のオークションのみ
- 不可: ライブ開始後のオークション、落札／決済、ユーザー管理、設定変更
- 管理者ロールと**兼任可能**（兼任時は通常の `/admin` も使える）

## 6. セキュリティ設定

### 6.1 二段階認証（2FA）の設定

> 強くお勧めします。アカウント保護に有効です。

1. 設定 → 「**二段階認証**」→「セットアップ」をクリック
2. **Google Authenticator** または **Authy** で QR コードをスキャン
3. 認証アプリに表示された6桁のコードを入力して「有効化」
4. **リカバリーコード**（10個）が表示されます → **必ず安全な場所に保存**してください

> ⚠️ リカバリーコードは認証アプリが使えなくなった場合の緊急ログイン手段です。紛失すると復旧できません。

### 6.2 二段階認証の無効化

設定 → 二段階認証 → 「無効化」→ 現在のパスワードを入力

### 6.3 パスワードの管理

- 8文字以上、英大文字・小文字・数字の組み合わせを推奨
- 他サービスと同じパスワードの使い回しは避けてください
- 定期的な変更（3〜6ヶ月ごと）を推奨

### 6.4 セキュリティ機能一覧

| 機能 | 詳細 |
|---|---|
| 二段階認証（TOTP） | Google Authenticator 等対応 |
| セッション管理 | ログアウト時にトークンを無効化 |
| 通信暗号化 | 全ページ SSL/TLS (HTTPS) |
| ブルートフォース対策 | ログイン試行 10回/分のレート制限 |
| 監査ログ | 管理操作の全履歴を記録 |

## 7. 通知設定

### 7.1 メール通知

設定 → 「**通知設定**」でメール通知の ON/OFF を管理できます。

| 通知種別 | 説明 |
|---|---|
| 落札通知 | 自分が落札した際に通知 |
| 入金確認通知 | 入金が確認された際に通知 |
| 発送通知 | 出品者が発送した際に通知 |
| オークション開催予告 | 開催前日に通知 |
| お気に入り商品通知 | 登録商品の出番が近い際に通知 |
| 支払いリマインダー | 未入金時のリマインダー |

### 7.2 LINE 通知の設定

1. 設定 → 「**LINE 連携**」→「LINE と連携する」
2. LINE の認証画面で許可
3. 連携完了後、LINE 通知設定で受け取る通知を選択

**受信可能な LINE 通知**

| 通知種別 | 内容 |
|---|---|
| 落札通知 | 落札商品・金額・請求書リンク |
| 発送通知 | 追跡番号・配送業者 |
| お気に入り出番通知 | 出番まであと XX 分 |
| お知らせ | 重要なシステム通知 |

### 7.3 テスト通知の送信

設定 → 通知設定 → 「**テスト通知を送信**」で動作確認ができます。

## 8. よくある質問

### アカウント・ログイン

**Q: パスワードを忘れました**  
A: ログイン画面の「パスワードをお忘れの方」からリセットできます。登録したメールアドレスにリセットリンクを送信します。

**Q: 二段階認証アプリが使えなくなりました（スマホを変えたなど）**  
A: セットアップ時に保存した**リカバリーコード**を使用してログインできます。ログイン画面で「リカバリーコードを使用」を選択してください。

**Q: 登録したメールアドレスを変更したい**  
A: マイページ → 設定 → プロフィール更新からメールアドレスを変更できます。変更後は確認メールが届きます。

### 入札・落札

**Q: 入札ボタンが押せません**  
A: 以下を確認してください。
1. サブスクリプション（bid プラン）に加入しているか
2. オークションがライブ中か
3. ブラウザを更新してみてください

**Q: 落札したのにキャンセルできますか？**  
A: 原則としてキャンセルは不可です。やむを得ない事情がある場合は管理者にお問い合わせください。

**Q: 価格がリアルタイムで更新されません**  
A: インターネット接続を確認し、ブラウザをリロードしてください。WebSocket 接続が切れている可能性があります。

### 支払い・配送

**Q: 入金後いつ発送されますか？**  
A: 管理者が入金を確認後、出品者に発送通知が送られます。発送期限は出品者によって異なります。

**Q: 配送先住所を変更したい**  
A: マイページ → 落札商品 → 対象オークション → 「配送先を変更」で変更できます。出品者が発送処理をする前までに変更してください。

**Q: 荷物が届かない・破損している**  
A: まず追跡番号で配送状況を確認し、問題がある場合は管理者にご連絡ください。エスクロー保護期間内であれば対応いたします。

### 出品

**Q: 商品を登録したがオークションに表示されない**  
A: 管理者によるオークションへの割当が必要です。登録後に管理者が確認・割当作業を行います。

**Q: 精算はいつ行われますか？**  
A: 管理者が取引完了を確認後、精算スケジュールに従って振込を行います。詳細は精算管理画面でご確認ください。
