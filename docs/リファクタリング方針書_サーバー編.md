## 2. 目標アーキテクチャ

```
HTTP Request
    │
    ▼
┌─────────────────────────────────────────────┐
│  Controller  （リクエスト受付・レスポンス返却のみ）│
│  • バリデーション（FormRequest）              │
│  • Actionの呼び出し                          │
│  • DTOをJSONにシリアライズして返す            │
└───────────────┬─────────────────────────────┘
                │  uses
                ▼
┌─────────────────────────────────────────────┐
│  Action  （1クラス1ユースケース）             │
│  • execute() メソッド1つのみ                 │
│  • Repositoryを呼ぶ                         │
│  • イベントを発火する                        │
│  • DTOを返す                                │
└───────────────┬─────────────────────────────┘
                │  uses
                ▼
┌─────────────────────────────────────────────┐
│  Repository  （DBアクセスの抽象化）           │
│  • Eloquentをラップ                          │
│  • テスト時はモックに差し替え可能            │
└───────────────┬─────────────────────────────┘
                │  returns
                ▼
┌─────────────────────────────────────────────┐
│  Model   （エンティティ定義・リレーション）   │
│  • $fillable, $casts, リレーションのみ       │
│  • クエリロジックは持たない                  │
└─────────────────────────────────────────────┘
```

```php
// app/DTOs/LiveStateDto.php
readonly class LiveStateDto
{
    public function __construct(
        public int    $auctionId,
        public string $auctionTitle,
        public string $status,
        public float  $countdownSeconds,
        public array  $lanes,
        public bool   $showConsentScreen = false,
        public ?int   $startingCountdown = null,
        public ?bool  $entranceAllowed   = null,
        public ?string $entranceAt       = null,
        public ?string $startAt          = null,
        public ?int   $venueOpenMinutes  = null,
        public ?string $message          = null,
    ) {}

    public static function fromArray(array $data): self
    {
        return new self(...$data);
    }

    public function toArray(): array
    {
        return array_filter(get_object_vars($this), fn($v) => $v !== null);
    }
}
```

#### `AuctionResultDto.php` 設計

```php
// app/DTOs/AuctionResultDto.php
readonly class AuctionResultDto
{
    private function __construct(
        public bool   $success,
        public string $message,
        public array  $data = [],
    ) {}

    public static function success(string $message = '', array $data = []): self
    {
        return new self(true, $message, $data);
    }

    public static function failure(string $message, int $statusCode = 400): self
    {
        return new self(false, $message);
    }

    public function toResponse(int $successCode = 200): \Illuminate\Http\JsonResponse
    {
        return response()->json($this->toArray(), $this->success ? $successCode : 400);
    }
}
```

#### `PauseAuctionAction` 設計例

```php
// app/Actions/Auction/PauseAuctionAction.php
class PauseAuctionAction
{
    public function __construct(
        private readonly CountdownService $countdown,
    ) {}

    public function execute(Auction $auction): AuctionResultDto
    {
        if ($auction->status !== 'live') {
            return AuctionResultDto::failure('開催中のオークションのみ一時停止できます。');
        }

        foreach ($auction->lanes()->where('status', 'active')->get() as $lane) {
            $this->countdown->pauseCountdown($lane->id);
        }
        $auction->lanes()->where('status', 'active')->update(['status' => 'paused']);

        broadcast(new AuctionStatusChanged($auction->id, 'paused', 'オークションが一時停止されました'));

        return AuctionResultDto::success('全レーンを一時停止しました。');
    }
}
```

## 6. Phase 4: Modelのクリーンアップ

### 方針: Modelはエンティティ定義のみに限定する

Model に記述してよいもの:
- `$fillable`, `$casts`, `$hidden` 等のプロパティ
- リレーション定義（`hasMany`, `belongsTo` 等）
- シンプルなアクセサ（`getXxxAttribute`）

Model から移行すべきもの:
- クエリスコープ → Repository に移行
- ビジネスロジック → Action/Service に移行
- 静的ファクトリメソッド → Repository に移行

### 具体的な対象

#### `BidParticipant.php` の場合

```php
// 現状（移行対象）
class BidParticipant extends Model
{
    // スコープ → BidParticipantRepository に移行
    public function scopeActive($query) { ... }
    public function scopeForItem($query, $itemId) { ... }
    public function scopeForUser($query, $userId) { ... }

    // 静的ファクトリ → BidParticipantRepository に移行
    public static function participate(...) { ... }

    // ビジネスロジック → LeaveBidAction に移行
    public function deactivate() { ... }
}
```

```php
// 改善後（Modelに残すもの）
class BidParticipant extends Model
{
    protected $fillable = [...];
    protected $casts    = [...];

    public function user(): BelongsTo { return $this->belongsTo(User::class); }
    public function item(): BelongsTo { return $this->belongsTo(Item::class); }
}
```

#### `Auction.php` の場合

```php
// 現状: 351行（移行対象メソッド多数）
class Auction extends Model
{
    public function canStart(): bool { ... }  // → Action に移行

    public function getAuctionSettings(): array { ... }  // → AuctionService に移行
    public function getPriceIncrementRate(): float { ... } // → AuctionService に移行
    // ...
}
```

```php
// tests/Unit/Actions/Bid/LeaveBidActionTest.php
class LeaveBidActionTest extends TestCase
{
    public function test_正常に入札離脱できる(): void
    {
        $item = Item::factory()->state(['status' => 'live'])->create();
        $user = User::factory()->create();
        BidParticipant::factory()->create(['item_id' => $item->id, 'user_id' => $user->id, 'is_active' => true]);

        $action = app(LeaveBidAction::class);
        $result = $action->execute($item, $user->id);

        $this->assertTrue($result->success);
        $this->assertDatabaseHas('bid_participants', ['item_id' => $item->id, 'user_id' => $user->id, 'is_active' => false]);
    }

    public function test_ライブでない商品への離脱はエラー(): void
    {
        $item = Item::factory()->state(['status' => 'sold'])->create();
        $user = User::factory()->create();

        $action = app(LeaveBidAction::class);
        $result = $action->execute($item, $user->id);

        $this->assertFalse($result->success);
    }
}
```
