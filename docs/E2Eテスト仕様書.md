## 1. テスト環境・前提条件

### 1.1 テスト環境

| 項目 | 内容 |
|------|------|
| フロントエンド | React + TypeScript + MUI |
| バックエンド | Laravel (PHP) + MySQL |
| リアルタイム通信 | Laravel Reverb (WebSocket) |
| 認証方式 | Laravel Sanctum (Cookie-based SPA認証) |
| テストデータ | DemoDataSeeder使用（25オークション、各200アイテム） |

### 1.2 テストアカウント

| 管理者 | admin@example.com | password |
| 出品者 | seller1@example.com | password |
| 参加者 | participant1@example.com | password |
