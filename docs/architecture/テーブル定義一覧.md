## 注意事項・既知の乖離

1. **bid_limit_prices テーブルの複合インデックス**  
   本番環境に `idx_active_limits (item_id, is_triggered, limit_price)` が存在するが、マイグレーション定義に反映されていない。手動で追加された可能性がある。

2. **マイグレーション重複エラー**  
   2026_05_01_000001 というタイムスタンプで 2 つのマイグレーション（`add_is_anonymous_to_items_table` と `add_is_test_to_users_and_test_mode_setting`）が存在する。データベースシステムが処理できるかどうかは Laravel のマイグレーションスケジューラ依存。

3. **削除されたカラムの履歴**  
   items.reserve_price, estimated_price, bid_increment は @deprecated としてモデルのコメントに記載されているが、マイグレーションでは削除されていない。

4. **レガシー bids テーブル**  
   bid_participants と bid_events に機能分離された後も down migration で復元スクリプトが残されている。

5. **SoftDeletes の users テーブル**  
   users テーブルに deleted_at があるが、マイグレーション 2024_01_16_000001 で追加（softDeletes()）されている。
